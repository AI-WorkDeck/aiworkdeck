# 我的愿望

- 许愿人：maryhung0904
- 业务领域：法律研究 / 法律资讯编辑
- 这件麻烦事：法律资讯或月刊发布前，要逐篇核查法规名称、文号、效力状态、案例案号、裁判要旨、发布日期与施行日期，还要检查链接、署名以及标题与正文的一致性。工作重复繁琐，容易漏项；尤其需要区分“已确认有误”和“暂时无法核实”，不能把猜测当成结论。
- 用户会怎么说：“请审校这份法律资讯，按我们约定的范围逐项核查。每个问题都给出位置、原文、判断依据、可靠来源和修改建议；查不到或无法确认的内容标为‘待确认’，不要猜。”
- 先问什么：
  1. 稿件文件、预计发布日期和适用法域是什么？
  2. 需要核查哪些版块和项目，是否有明确排除的版块？
  3. 是否允许联网核验，优先采用哪些权威来源？
  4. 只要问题清单，还是还需要修订稿？是否有固定格式和写作规范？
- 步骤和标准：
  1. 解析标题、正文、作者栏、日期、脚注和链接，按约定范围建立逐项清单；排除项不擅自检查。
  2. 优先用法律法规数据库、立法或司法机关官网等权威来源核对名称、文号、案号、日期、效力和引用内容，保留来源链接及检索日期。
  3. 检查链接能否访问、是否指向所述材料，并核对标题、正文、署名和期号等内部一致性。
  4. 按“发布前必须处理 / 建议修改 / 待确认”分类输出。每项写明位置、原文、问题、依据和建议；无法取得全文或权威来源时，只标“待确认”，不判定为错误。
  5. 未经要求不改写原文；需要修订稿时，保持原意和风格，并让修改可追踪。
- 怎么算做完：约定范围内每一项都有“已核验 / 待确认 / 不适用”的状态；所有已确认问题均可定位、可复查且有来源，所有“待确认”项都说明缺少什么证据；最终形成一份发布前问题清单和复查汇总，若用户要求修订稿，则同时交付修改可追踪的版本。
