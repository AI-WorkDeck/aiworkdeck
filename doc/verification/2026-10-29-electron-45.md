# Electron 30 → 45 兼容验收（dev-board#1624）

用户要求升级 Electron、做好兼容性测试，暂不发版。应用版本保持 0.74.0；不创建版本 tag、Release，不部署或替换用户客户端。

## 变更与环境

- Electron 30.5.1 → 固定 45.1.0，实际 Chromium 156.0.8078.49 / Node 24.22.1。
- ClipboardItem/Blob 异步读取、停止/重启取消与首读保护；保留原图片优先、去重和 macOS 文件捕获边界。
- 明确执行 `install-electron`，桌面 CI 使用 Node 24；开发安装 Node >=22.12.0。
- 最低 macOS 13 Ventura（本项目 Mac ARM64）；Electron 45 仍支持现有 BrowserView/旧导航方法。electron-builder 24.13.3 及已有补丁保持。
- BrowserView UA 使用实际运行时平台与 Chromium 版本，去除 Electron 标记。

## 本机验证

主任务运行完整桌面套件：703 通过、4 跳过、0 失败（普通431、关于3、原生269）。20语种令牌、品牌文案校验通过。H5、zetaoffice、macOS ARM64 后端 JAR 构建通过。首次迁移时两项旧同步剪贴板替身失败，替身改成实际异步契约后通过。

真实 Electron 测试保持沙箱，使用生产 preload 和 BrowserView 注册表，验证 IPC、订阅清理、DOM File 到实际文件路径、WASM/共享内存/worker、面板隐藏恢复/历史与实际下载。后端请求取消回归验证超时请求不重放、后续请求成功，正常退出。主任务证据：`awd-runtime-compat-dOCJQh/result.json`，`awd-gate-abort-edwy5v`（系统临时目录）。

四格式脚本：`frontend/tests/desktop-e2e/electron-upgrade.mjs`。使用新生成文件，启动前隔离并回读 Electron 路径、Java user.home、H2、storage 与端口；不读取用户数据库或更改个人客户端。先用 30.5.1 建合成 profile，再用 45.1.0 验证 localStorage 延续。

| 格式 | 实际路径 | 验收 |
|---|---|---|
| Word | LOWA WASM webview | 正文显示、IME 输入、正常自动保存到原 DOCX、关闭重开；原段落与加粗保留 |
| Excel | LOWA WASM webview | 网格显示、B2 输入、正常自动保存到原 XLSX、关闭重开；原单元格及公式保留 |
| PPT | LOWA WASM webview | 中文标题/正文显示、文本框输入、正常自动保存到原 PPTX、关闭重开；原标题/正文及两页结构保留 |
| PDF | Chromium PDF iframe | 两页正文、滚轮至2/2、关闭重开至1/2；原文件 SHA256 不变。未验证原生查看器批注/下载，应用无该路由自动保存契约 |

子代理最终完整运行 `awd-electron-upgrade-aY39TG` 退出0，主任务另行读取结果、OOXML断言与四类截图。前三轮测试工具调试分别暴露 webview 焦点、IME 提交前 Escape、虚拟 viewport 与原生坐标不一致；未将这些失败轮当成兼容通过依据。最终采用实际窗口大小，真实正文/翻页截图经人工核对，未调用手动或强制保存。

主任务独立完整复跑 `awd-electron-upgrade-xRIVYn` 同样退出0，另行核对四类重开截图与 PDF 第二页；无强制保存或强杀，个人客户端 PID/监听端口前后不变。后续剪贴板专项复核发现迟到 Blob 可能覆盖快捷键复制的新指纹，三项负对照先失败、修复后全部通过。

主任务另跑中文+英文混合 IME 提交，`awd-electron-upgrade-rWOjwv` 退出0；三格式中文/英文输入、自动保存与重开均通过，重开截图已逐类复核。初次中文断言把跨多个OOXML文字段当成一个XML子串而失败（`PdpLCA`），解包确认文本实际已正确保存；修为按合成文字内容断言，没有修改产品保存逻辑。

## CI 与签名包

首轮手动构建 `40866116054` 的 Mac 运行时探针在 IPC 尚未到达时读取事件数组，现改为等待实际事件及取消订阅后的屏障事件；Windows 单测在宿主 Windows 解码模拟 Mac file URL 时失败，Mac 分支现明确按 POSIX 路径解码。未跳过失败用例。构建与原生升级按精确提交验收，最终 run、签名和原生升级结果以 [PR #1283](https://github.com/AI-WorkDeck/aiworkdeck/pull/1283) 验证记录及台账落实记录为准；本文件不将尚未完成的构建写成通过。测试包仅来自手动 workflow_dispatch；release/sync-mirror 保留 tag 门禁。

## 证据边界

本机四格式验证是 macOS 源码运行时与默认 WASM 编辑器，不等同于签名安装包或原生 LOK 编辑器。未验证 Windows ARM64 真机、macOS 13 真机、真实用户旧数据库迁移、所有第三方网站与摄像头/麦克风硬件。默认系统能力的单测不能替代这些专门验收。浏览器/Electron 自带 PDF 批注与另存尚未验收。
