# 顶栏对齐与聊天展开稳定性（2026-10-28）

对应 dev-board #1567、#1568。全部用合成项目/聊天数据；未发布版本或升级用户客户端。

## 修复与基线

- 顶栏：真实 H5 的 Mac CSS 模式下，项目名文本比自身控件中心高 1px，切换箭头高 4px，状态文字低 1px。紧凑模式另有 2px 整行下移；720px 的旧纵向布局使工具越出固定高度。修正文本居中、共用高度与窄屏横向布局，保留省略和下拉菜单。
- 聊天：经典滚动条从 0 变为 14px 时，居中正文横移 7px，输入框不动；首次手动展开还让 scrollTop 从 0 跳到 697。正文滚动容器预留对称槽位；操作组、思考与工具详情手动展开/收起通过显式事件暂停跟随。流式自动展开不发此事件。

## 验证

- 主任务重跑真实 H5：中英 × Web/Mac/Windows CSS × 1920/1440/1024/720px 共 24 组通过；检查文本中心、实际内容无重叠、窄屏下拉可见。查看中 Mac 宽屏及英 Mac 窄屏截图。基线 `/tmp/titlebar-baseline-final/report.json`；主任务复跑 `/tmp/titlebar-parent/report.json`。
- 子代理在隔离 Electron 窗口加载当前 H5，使用真实 CoreGraphics 鼠标事件：空白拖动窗口移动 (55,35)，项目名进入重命名、切换器展开/关闭、中央两种模式切换通过。主任务读取报告并复核实现，未自行重复原生鼠标操作。证据 `/tmp/awd-titlebar-native/report.json`。
- 35 项标题栏、窗口拖拽区域、聊天展示及思考卡定向回归通过；前端构建、20 语言覆盖、事件绑定与设计系统检查通过。构建产生的无关插件产物已还原。
- 主任务独立运行 `scrollbar-stability.mjs`：两种浏览器启动模式 × 四种宽度/方向 × 三次展开收起，共 24 次溢出切换通过；正文坐标/宽度稳定，对话模式与输入框同轴，手动操作保留 scrollTop。思考、旧内存消息内联思考、过程头、工具结果四类入口与返回最新、流式增长跟随均通过。经典模式双侧槽宽 28px；无头默认隐藏滚动条模式仍预留 30px，不将它称为 macOS overlay。报告 `/tmp/chat-scrollbar-parent-final/metrics.json`。

## 边界

平台 CSS 模拟不等于 Windows 原生窗口测试；隔离 Electron 不等于签名发布包或用户客户端实测。真实 macOS overlay 滚动条未专项验证。未调用真实模型、读取客户材料或改变后端逻辑。
