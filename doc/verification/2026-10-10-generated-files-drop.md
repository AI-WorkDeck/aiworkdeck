# 新生成文件目录与跨应用拖入验证

关联 dev-board#1181、#1182。源码交付与发版分开，未升级用户安装客户端。

## 范围

- 新建文件优先使用明确目录；未指定时继承本轮开始时的活动文件目录，打开参考文件不改变默认；明确 0 为项目根。内部暂存目录及后代不作为默认输出目录。
- 对话新增文件按后端真实 ID 及项目身份拖入资源树，名称仅作展示，历史缺少可靠 ID 的条目不猜测。接收端同时校验项目身份；拖拽过程中透明弹层遮罩不拦住文件树。
- 外部拖放在原生事件仍有效时提取 files/items 并开始读取无路径 File 的字节。Finder 的原有路径复制不变；无路径但可读取的文件由桌面受限暂存，再复用 import-local，成功和失败都清理 token。file URL 字符串不授权磁盘读取。
