# 左侧面板样式与交互标准

2026-09-15 · dev-board #648 · 以资源管理器和插件广场为基准。

## 统一规则

- **外壳负责标题。** 内部不重复画页面标题；白色/深色表面随主题切换，不用灰底叠白卡片。
- **单一令牌来源：** `frontend/src/App.vue` 的 `--awd-panel-*`。左右边距 10px，同组间距 8px，跨组 14px；分组头 26px；正文 12px、辅助文字 11px；控件圆角 6px。主操作可用 32–34px 高按钮。
- **列表优先。** 项目字段、统计、录音记录用平铺行与细分隔线；只为实际状态/输入区加背景。常态不使用绿色竖线、卡片套卡片或与主题不一致的蓝底。
- **颜色按用途。** 普通文字 `--awd-panel-text`，说明 `--awd-panel-text-2`，可点击文字 `--awd-accent-text`；危险/错误用 `--awd-danger-text` 配 `--awd-danger-soft`。颜色不单独承担状态含义。
- **先主流程，后选项。** 默认能找到选文件、处理方式和预览入口；可选补充词与识别选项渐进展开，展开/收起不清空输入。密码与生成动作在预览成功后出现。
- **状态就近。** 等待时明确显示处理中并禁止重复提交；失败显示就地错误及原有重试入口；生成成功打开副本并显示后续步骤。不得把未确认的操作写成成功。
- **窄栏适配。** 220/260/420px 栏宽不能横向溢出；长文件名换行或省略，不能挤掉状态与按钮。按容器宽度调整列数。容器查询只能影响后代，不能在查询内部修改被查询容器自身的 padding。

## 当前脱敏路径

1. **选择文件：** 浏览项目文件或导入当前标签；处理前调用 `prepareFile` 保存目标编辑器。切换文档标签不自动更换左侧所选文件。
2. **选择模式：** 默认编号替换，可复敏；星号遮蔽不可复敏；PDF 强制不可逆黑框。格式限制和不可逆说明保持可见。
3. **按需修正规则：** 默认识别公司、中文姓名、手机号、身份证、邮箱、银行卡。前置“补充敏感词（可选）”和“自动识别的信息类型”均可展开；保留词在识别选项中排除误识别。规则变化使旧预览失效。
4. **核查预览：** 本地规则预览，不调用大模型。预览显示后才提供复敏密码及生成按钮；编号模式密码至少 10 字符。若预览后文档又保存了修改，必须重新预览。
5. **生成副本：** 成功打开副本；编号模式下载独立加密复敏文件，原文件保留。下载失败可重新下载。需在切换面板前确认保存复敏文件。
6. **编辑与复敏：** 用户可编辑副本；“复敏这份结果”选中本次副本并沿用加密映射，再输入密码生成复敏文件。PDF/星号不能复敏。
7. **AI 边界：** 此面板不自动发送文件；普通 AI 对话可能带入历史/项目上下文。原件、复敏映射和复敏结果不应随脱敏材料提供给 AI。原有提示保留。
