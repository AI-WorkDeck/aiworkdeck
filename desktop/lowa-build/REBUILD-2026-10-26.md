# LOWA 内核候选范围复核（dev-board#1509 / #1511）

本轮起点是表格行列标题美化。用户同时要求回查近期迭代中受内核限制的问题，必要时合并重烧。下表区分已完成、候选与仍需专项调查的项目，不能将补丁应用成功称为实际引擎验证通过。

## 基线

2026-10-26 本机安装包的四个 LOWA 文件在按 `.encodings.json` 解压后，SHA-256 全部匹配 [RECIPE.md](RECIPE.md) 的 `24.2.8-zhcn-r6`。r6 已由 [PR #1164](https://github.com/AI-WorkDeck/aiworkdeck/pull/1164) 交付，包含原生审阅几何、部分 ElyOffice 补丁和资源包瘦身。旧文档中的“待重烧 r6”不能作为未完成清单。

## 本轮候选

| 项目 | 来源与已确认机制 | 边界与验收 |
|---|---|---|
| Calc 行列标题字体与配色 | 用户截图；`ScHeaderControl` 构造时缓存字体，绘制时使用独立控件调色板，Vue CSS 不作用于这些像素。旧引擎 UNO 样式探针不能可靠改变缓存字体或原生选中底色。 | 仅改变行列标题的 UI 字体及局部配色；保持单元格格式与鼠标逻辑。使用既有 AppBackground 识别深浅主题，保留高对比原绘制路径。实测需覆盖 DPR、缩放、选行列、调整尺寸、主题切换和保存重开。 |
| Qt5 WASM 点击时间戳 | [PR #1136](https://github.com/AI-WorkDeck/aiworkdeck/pull/1136) 记录隔时点击误判双击及拖移吞词。精确 Qt fork 中 `processMouse`、`wheel_cb` 将 Unix 纪元毫秒 `double` 隐式传给 WASM32 `ulong`，已超其范围；源码不是字面传零，旧二进制的转换值应由实际测试判断。 | 改用 Qt 已有无 timestamp 重载，其使用应用启动时初始化的 `QElapsedTimer::elapsed()`；投递方式、坐标与滚动方向不变。保留生产 wrapper 对旧引擎的补偿。慢击、真正双击、禁用补偿的拖移/撤销及滚轮必须做旧新对照。 |

Calc 字体为包内已存在的 Liberation Sans 9pt，经 `Window::SetPointFont` 按设备 DPI 转换。配色逐项对照 `design/tokens/awd-palette.json`，不改文档字色、背景或内容。此局部补丁不等同于整个 Qt chrome 深色化；滚动条、原生菜单等仍是另外的范围。

## 用户追加的本轮修复（#1515）

用户要求本轮发现的问题直接修复，不留后续。首个 r7 候选的裸画布列宽拖动已由主任务再次复现失败。
`HelpTextWindow` 在 VCL 中已有鼠标穿透语义，但 `QtFrame` 未把真正的
`SalFrameStyleFlags::TOOLTIP` 映射为输入透明窗口，WASM compositor 的 `windowAt`
也未检查 `WindowTransparentForInput`。补丁在 WASM 的真实 tooltip 分支补这个标记，
并使 compositor 命中遵守标记，保留提示框显示。不能跳过所有 `Qt::ToolTip`：
可交互的 ComboBox popup 同样使用这个类型，其分支必须保留。

补充候选 r7b 已完成重编：相同裸画布测试在旧 r7 列拖动处失败，新 r7b 两种 DPR 共114项通过、零跳过，涵盖提示框可见、正反向行列尺寸、双击、撤销与保存重开。真实字体下拉框两种 DPR 均通过；共享内核607项与15字体回归通过。PDF走独立浏览器预览，路由/导出/恢复13项通过。首轮初始化超时未归因，保留失败记录和诊断；不能把单独重跑通过称为启动故障已修复。哈希、实际角色与验收边界见 `RECIPE.md`。临时云资源已全部清理，候选未发布。

## 验证纪律

- `node --test desktop/tests/lowa-build-patches.test.js desktop/tests/lowa-qt-patches.test.js` 仅验证补丁锚点、幂等、失败拒绝与令牌对应。
- 核对构建源码提交、Qt gitlink、Writer / Calc / Impress 三模块及 zh-CN 资源；记录产物 SHA-256。
- Word、Excel、PPT 使用真实引擎检查打开、选择/输入、滚动、导出重开。PDF 使用独立预览/批注路径，不把 LOWA 结果当作其验收。
- 真实像素/交互结果与源码审阅分开记录。候选在完成编译与运行验收前不更新默认下载地址、不宣称已发布。
