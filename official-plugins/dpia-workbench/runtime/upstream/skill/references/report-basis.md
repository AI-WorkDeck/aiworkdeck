# GDPR报告依据

本版实质分析使用EDPB认可的WP248 rev.01 III.D(c)和附件2，具体官方定位见workflow.md；GDPR35(7)及相关适用条款是法律基础，模板只是呈现格式。

有用户指定且适用的模板时优先使用，核对发布机构、现行版本、用途及栏目；没有则依据上述必要内容组织。模板缺项须补足，草案/工作译本属性不隐瞒；不从别国模板推导本案义务，不机械要求所有国家采用同一表。

默认内部稿是简洁风险与整改清单，不提前套正式模板。正式报告按outputs.md分完整内容稿和待完善草稿；后者未知事实栏留空并批注、依赖结论未定，不能宣称评估已完成。各项依据记录到具体法条/指南定位、事实和报告位置，不以栏目有文字证明已分析。

没有原件不等于不能评估；未核验当地要求须说明限制，不冒称适配完成。非GDPR法域报告不在本版范围。

正式内容须对照WP248附件2及本案适用条款核对覆盖，而不是只统计风险项数。逐目的分别说明已知事实、可论证的候选法律基础及适用条件、排除理由和剩余缺口；没有最终基础不等于不能开展已有部分的分析。合法性及特殊类别/犯罪数据、适用时终端存取衔接，复用并更新[eu.md](eu.md)规定的内部评估子判断，不等到模板阶段才首次检查，也不能把底稿中的有限判断丢失或扩大成确定勾选。相关经批准行为准则的适用与遵守情况（GDPR35(8)）须有判断或明确未决项，不要求为无关领域虚构准则。

逐目的法律基础使用“候选路径—已知事实如何支持/限制—尚缺成立条件—当前结论”的紧凑说明，写入EU-C02.analysis并进入正文。候选须由事实支持，不为凑齐表格穷举全部Art6选项；没有可支持的候选时解释原因。最终基础未定不妨碍检验合同客观必要性、同意选择或合法利益衡量等实际相关路径。业务方补充合同关系、拒绝后果等事实，不要求业务方替Skill选择法条。报告中“未定”不能独占整行而把这项分析留给未来。

现有/拟议权利实现、角色和处理者安排、跨境、必要性/比例性、个人风险与措施、DPO及适当的主体意见、事前咨询和复评各有具体分析或限定，不能仅以“全部未确认”代替。未知部分按outputs留空批注，不因草稿而删除对应问题。交付映射及检查见[report-release.md](report-release.md)。
