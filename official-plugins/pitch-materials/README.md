# 投标与提案（pitch-materials）

给潜在客户做投标书、服务方案、提案 PPT 时，从所里的积累里拼出一份专业初稿：

1. **业绩与团队库**：过往业绩（含对外称谓，用于脱敏）、律师简历、资质荣誉、标准服务说明、报价模板。可从「律所管理」插件导入已立案/已结案事项和所内律师。
2. **招标对照**：选一份招标文件，AI 逐条抽出资格要求和评分项（每条带原文出处，可跳回原文），再逐条对照库里的材料，标出满足、部分满足、缺材料；律师可逐条改结论，导出 Excel。
3. **生成材料**：按所里的 Word / PPT 模板生成投标书或提案初稿，自动挑相关业绩和律师，报价按报价模板算出（整数分计算，含大写金额）。生成后直接在编辑器里改，改完导出。
4. **对外脱敏**：对外材料默认把客户名换成「对外称谓」，生成后逐份检查库里的真实客户名是否仍出现在材料里；还可交给「文件脱敏」再出一份脱敏副本（Word）。

- 形态：Web 面板（工作区视图）+ 插件 JAR（库存储、报价计算、模板填充、写入项目文件）+ 技能（对话里调用同一工具）。
- 权限：`file_read`、`file_write`、`ai`（招标对照，`ai.request` 按用户 Credits 计费）、`lawfirm`（从律所管理导入，只读）。
- 库存放位置：插件设置（宿主数据库），**按用户隔离**。桌面版即本机；团队服务器上每位用户各一份，不跨用户、不跨律所共享。同事之间共享用「导出库」写入项目文件，对方「导入库」。

## 模板占位符

模板就是普通 Word / PPT 文件，在需要填内容的位置写 `{{字段}}`。中英文字段名等价（括号内为英文别名）。

单值字段：

| 字段 | 说明 |
|---|---|
| `{{律所名称}}` (`firm.name`) | 库里的律所名称 |
| `{{律所简介}}` (`firm.intro`) | 库里的律所简介 |
| `{{客户名称}}` (`client.name`) | 招标人 / 潜在客户 |
| `{{项目名称}}` (`project.name`) | 投标项目或提案主题 |
| `{{日期}}` (`date`) | 生成日期，如 2026年11月12日 |
| `{{团队负责人}}` (`team.lead`) | 选中律师中的第一位 |
| `{{服务方案}}` (`service.text`) | 选中的标准服务说明，多段 |
| `{{报价方式}}` (`quote.mode`) | 报价模板名称 |
| `{{报价合计}}` (`quote.total`) | 如 ¥360,000.00 |
| `{{报价大写}}` (`quote.totalUpper`) | 如 人民币叁拾陆万元整 |
| `{{报价说明}}` (`quote.note`) | 折扣、封顶、税费说明 |

列表字段：写在**表格行**里时，该行按条目逐行复制；写在表格外的**连续段落**里时，这组段落按条目整体复制；PPT 里写在表格外时，整页幻灯片按条目复制。没有条目时整行/整组/整页删除。

| 列表 | 字段 |
|---|---|
| 业绩 (`credentials`) | 序号 `no`、名称 `title`、客户 `client`、领域 `area`、年份 `year`、金额 `amount`、角色 `role`、简介 `summary`、律师 `lawyers` |
| 律师 (`lawyers`) | 序号 `no`、姓名 `name`、职务 `title`、领域 `area`、执业年份 `since`、教育 `education`、简介 `bio` |
| 资质 (`quals`) | 序号 `no`、名称 `name`、类型 `kind`、颁发机构 `issuer`、年份 `year` |
| 报价 (`quote`) | 序号 `no`、项目 `item`、计算 `basis`、金额 `amount` |
| 对照 (`matrix`) | 序号 `no`、类型 `kind`、要求 `requirement`、分值 `score`、结论 `status`、依据 `evidence`、缺口 `gap` |

写法：`{{业绩.名称}}`、`{{律师.简介}}`、`{{credentials.title}}`。对外模式下 `{{业绩.客户}}` 输出对外称谓。

## 开发

```sh
./official-plugins/pitch-materials/build.sh     # l10n 同步 + Web 测试 + JAR 测试 + 打 dist/pitch-materials-<版本>.zip
```

本地试装：把 zip 解压到 `~/.aiworkdeck/plugins/pitch-materials/`（开发安装另放一个 `.awd-dev` 空文件），在插件广场点「重新扫描」。上架走 `docs/PLUGIN_DISTRIBUTION.md` 的审核签名流程。
