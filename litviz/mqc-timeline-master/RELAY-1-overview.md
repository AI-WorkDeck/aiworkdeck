## 1. 这个 skill 是什么

**一句话**：把律师手上的案件材料，自动变成一张能直接打印、能溯源、排布上不会出错的诉讼时间轴。

**它与 v1（诉讼可视化重画）的分工**：v1 的推荐用法是「用户先自己画一张图，再由 skill 升级审美」，
它本身不直接吃材料。时间轴大师**直接吃案件材料**——判决书、起诉状、答辩状、合同、
聊天记录、录音文字稿。

**它不做什么**（作者反复定过，别越界）：

- 不做事件评价、法律判断、争点归纳。「什么是本案争议焦点」是法律判断，超出边界；
  判决书里的争点是法院写好的，照抄不算能力。
- 不替用户脱敏、不问用户是否脱敏。用户拿自己的卷宗出自己的图是他的事。
  **但维护者放进仓库的示例、文档、测试用例必须是脱敏的** —— 这是仓库卫生，不是产品功能。
- 第一版不做 OCR、图形型 PDF、照片。
  **已解决（见 ADR 0001、0002）：** 扫描件与照片走「探测 → 150 DPI 栅格化 → 模型逐页读图」，
  仍然不引 OCR 依赖（用的是 poppler 自带命令）。七份真实材料跑过，含一份 20 页纯扫描件。
  读图所得写成转写稿存档并作为材料进管线，全套忠实判据原封不动生效。
- 不做「事实与证据对照表」——那会破坏它的纯粹（它只画时间轴）。改成**溯源索引**：
  只说明图上已画出的元素分别出自材料何处。

## 2. 作者的核心理论（隐含进骨架，不作为卖点展露）

**三维立体坐标**：阶段（接案谈案 → 起诉 → 答辩举证 → 庭审 → 判决后 → 结案分享，
材料丰富度递增）× 受众（法官 / 当事人 / 客户 / 咨询人 / 同行）× 内容（标准化的图表与信息）。

这套理论用于超越 2017 年天同蒋勇《诉讼可视化》一书。第二篇主力文章还没发，
所以现阶段只隐含进 skill 骨架。

**受众那一维已经落地**：第三轮交互问「这张图呈报给谁」，答案直接决定风格。

## 4. 硬约束（这些是地基，改动前先想清楚）

**A4 打印约束是这个项目的真进步，不要退回去。** 律师插入 Word 的是 A4 纸，
所以按 A4 窄页边距下的真实打印效果设计。v1 的编号型是「卡宽固定 214px、画布随事件数变宽」，
不封尺寸——粘到 Word 或 PPT 里打印出来不能用。

**横轴的尺寸规则**（作者重申过两次）：

1. 编号型横轴上限是**轴上三条泳道、轴下三条泳道**
2. 期间型与日期型不涉及泳道，但横轴的真正极限是**横版 A4 的横向距离**
   （不是竖版，因为律师真要打印就该把纸横过来）
3. 超过极限就改用纵向，没有问题
4. **横轴绝不分页**（一根轴切在两张纸上没法读）；四五十个元素走纵向长图分页

**三种风格的画布规则不同**：奇川风与白描按打印准备（受 A4 约束）；
歸藏风画布无限制，因为它是电子版、不会打印。

**时间轴必须贯穿到底**：不许为了放泳道标注在左侧留出空白、把轴的起点往右推。
轴是主干，标注是附注。

## 5. 形态选择是自动的，不要再问用户

材料摄入后按元素数量自动选形态，阶梯永远有下一档：

```
5 个左右        → 横向，单侧或上下两侧
5 到 10 个      → 横向，同侧多带
更多            → 纵向（同样可以承载两侧）
非常多          → 纵向一直延续，分页
```

**为什么不问**：实测三份真材料，每一份都只有一种图种在几何上可行
（日期型全部被拒——它的适用面比想象的窄得多，见 RELAY-2）。
「列出可行的几种让用户选」在真实材料上落空，候选清单里只有一项。

## 6. 工作方法（作者定的循环，不要另起做法）

```
上传真实案件材料 → 出图 → 发现问题 → 改数学模型的规则 → 下一份材料
```

一份材料跑一轮，每轮固化三样：**脱敏 fixture、守卫、台账记录**。
下一份开跑前先让全部守卫过一遍。
材料顺序从规整到杂乱：判决书 → 起诉状答辩状 → 带表格的证据目录 → 最杂的。

**留一份不提前看的材料**，等管线成型后直接跑，验它是真的通用，
还是只被针对前几份调出来的。
