# 卡住了看这里：报错速查

**一个地方查完，不用翻别处。** 每一条给三样：这句话什么意思、谁该动手、怎么办。

---

## 先分诊：三类，只有一类需要你（用户）做事

| 你看到的 | 是什么 | 谁动手 |
| --- | --- | --- |
| 「句 12: …」「部分 3: …」这种带句号或部分编号的 | 模型这一步答得不合规，管线把它退回去重答 | **agent 自己改**，你不用管 |
| 「缺 xxx.json」「先跑 read」 | 步骤顺序不对，少了上一步的产物 | **agent 自己补**，跑一次 `next` 就知道缺哪个 |
| 「找不到 soffice」「node 未安装」 | 机器上少一个外部工具 | **你装**，或者接受少一种格式 |

还有第四种，**它根本不是报错**：图种自动落档、某一轮被跳过、某几个事项被范围筛掉。
这几种下面单列一节。

---

## 一 · 看着像报错，其实是设计如此

| 你看到的 | 实际发生了什么 |
| --- | --- |
| 「日期型：…超过 8 格的上限…请改用编号型」 | **图已经出好了。** 日期型这一档不成立，阶梯自动落到编号型。编号型是阶梯的底，永远画得出。不需要你改材料 |
| 「横向排不下（…）故改用纵向」 | 同上，自动落档。事项多到一页放不下会继续分页，事项数没有上限 |
| 「只有一份材料（…），跳过第一轮」 | 只有一个答案的问题不问你，这是故意的。后面括号里会告诉你跳过了什么 |
| 「材料只覆盖一小段时间，不必再选时间段」<br>「材料里只有 N 个日期，不必再选时间段」 | 第二轮同理跳过。时间分不出几档、或者日期少于八个时，问了也只有一个答案 |
| 「第五轮跳过（白描 / 歸藏风 不需要标红）」 | 深红只在奇川风里有意义。白描是单色，歸藏风有自己的视觉规则 |
| 「这些事项未经逐字核验」 | 那几项出自读图（扫描件、照片），没有文字层可以逐字比对。图是对的，只是请你自己复核一遍那几条 |

**判据一句话**：只要屏幕上出现了「出图：…」那一行，图就已经写到磁盘上了。

---

## 二 · 真的停下来了：出图前被拦住

管线只有**一类**情况会在出图前停：**写的字超过这一档算出的容量**。有两处会报：

    事项 3: 47 字超过容量 30 字，请改短

- **什么意思**：这一档的几何只放得下 30 字，写了 47 字。
- **为什么不截断**：截断等于从材料里删字，还留个记号说这里有东西你看不到；缩字号
  同理，印出来读不了。
- **怎么办**：agent 把那几条改短再跑一次 `render`。**你不用动手**，也不用改材料。
- **想让容量变大**：少勾几段（`budget` 只勾要的部分），或者让事项数降下来。
  事项越少每张卡越宽、能写的字越多。

另一处是**图名**：降到最小字号、折成两行仍放不下时，会报出上限并要求改短。处理方式
一样，把图名改短再跑 `render`。

## 三 · 步骤类：缺文件、顺序乱、换了会话

| 报错 | 怎么办 |
| --- | --- |
| `缺 state.json，先跑 read` | 从头开始：`python scripts/pipeline.py read <材料...>` |
| `缺 verdicts.json` / `parts.json` / `skeleton.json` / `items.json` | 这一步要模型先写那份 JSON。形状与判据现查：`python scripts/pipeline.py shape verdicts.json` |
| 不知道走到第几步了 | `python scripts/pipeline.py next`。它按**产物**判断，不靠自称，所以换会话、跑错顺序、文件写坏之后都问得出来 |
| `没有第 5 项，请报 1 到 4` | 风格只有三档加一个「让我定」：1 白描、2 奇川风、3 歸藏风、4 由它定 |
| `剔完没有事项了` | 勾选的范围里没有可画的内容。放宽范围：`span 全部` 或 `budget all` |

## 四 · 模型答得不合规：这些是退回重答，不是失败

**这一整类都是 agent 的活。** 列在这里是为了让你看懂屏幕上在发生什么，以及在你
自己核对图的时候知道它拦住过什么。

| 报错 | 拦的是什么 |
| --- | --- |
| `N 句未判定` | 要求逐句表态。一个跳过了四十句的模型和一个读完四十句、认定其中没有事件的模型，输出本来长得一样，逐句表态才分得开 |
| `raw 在该句中查不到，不得改写时间表述` | 拦的是把日期推算出来。「次年初」写成 2017/1/1，材料里根本没这么说 |
| `判为 exact 并给出 …` | 「2020 年」判成 2020/1/1 是凭空加精度，材料只说到年 |
| `不是该句的子序列` | 拦的是改写。只许删字：换一个词、调一次词序、补一个字都不行 |
| `N 句没有落在任何部分里` | 划分漏了句子。漏掉的那几句会整段消失在图外，且没人会发现 |
| `句 N 同时属于部分 X 与 Y` | 勾两个部分会把同一件事画两遍 |
| `部分 X 与部分 Y 同名` | 同名的部分你没法勾选 |
| `部分 X 里没有任何事项句` | 那一部分全是程序性文字或约定，画不出东西 |
| `这份材料不该用期间型` | 期间型的论点是重叠关系。只有一段、或几段互不重叠时，它不比编号型多说任何东西 |

## 五 · 环境类：少一个工具

跑一次环境自检，它逐项列出缺什么、缺了会退化成什么样。自检脚本属于共享内核：完整
仓库里是 `python3 ../mqc-litigation-visual-redraw/scripts/doctor.py`，SkillHub 的
单目录分发包里内核随包带上，直接跑 `python3 scripts/doctor.py`。
**没有一项是装不上，都是少一种格式**：

| 缺什么 | 后果 |
| --- | --- |
| LibreOffice 或 poppler | 出不了 PNG。SVG 母版照常交付，插进 Word 一样能用 |
| poppler 的 `pdftoppm` | 读不了没有文字层的扫描件与照片。有文字层的材料不受影响 |
| node | 出不了溯源索引 docx。图照常出 |
| `python-docx` | 读不了 `.docx` 材料。把材料另存成 txt 或 PDF 即可 |

**每一种格式独立守护**：任何一种失败都只是少一种格式，绝不影响已经写好的 SVG。
