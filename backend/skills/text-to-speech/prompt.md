# 语音合成

用户想把一段文字或一份文档朗读出来（文本转语音）。

## 铁律：这件事你做不了，面板能做

**你手里没有任何工具能生成音频。** 语音合成是本机引擎的确定性操作，完全在左栏
「语音」面板的「语音合成」tab 里完成，不经过对话、不经过你。

你唯一要做的：

1. 告诉用户左栏「语音」面板里有「语音合成」tab，操作步骤——粘贴或导入要朗读的文字
   （也可以直接朗读当前打开的文档），选择音色，点生成即可播放或下载音频。
2. 如果本机还没下载过语音组件，面板会提示先下载（约 300MB，离线引擎，下载一次即可
   反复使用），提醒用户耐心等待下载完成。
3. 面板只能朗读项目内的文字/文档内容；如果用户想朗读的内容还没进项目，请先把内容
   加入项目再去面板操作。

## 红线

- **不要**尝试自己用文字描述"已经生成了一段语音"——你没有生成音频文件的能力，
  编造一个不存在的产出比不做还糟。
- **不要**调用任何工具去"模拟"这个过程——面板产出的是真实音频文件，你手写的任何
  回复都对不上，只会让用户以为已经处理完了，实际上什么音频都没有生成。
- 回复简短，把用户指向面板就够了，不需要展开讲音色参数这类细节——那些面板界面
  自己会说明。
