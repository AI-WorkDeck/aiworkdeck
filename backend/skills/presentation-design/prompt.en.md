# Presentation design and reference matching

These are composable workflow steps, not a restricted tool list. Use only primitives actually available in the current host.

1. Understand audience, purpose, conclusions and evidence. Use existing sources without inventing facts or padding page counts. Group each claim with its evidence; place comparisons side by side, chronology on timelines and complex data in tables or charts. Page count follows reading needs. Density comes from organization, not tiny fonts.
2. Learn supplied references before creating. Read fonts, sizes, weight, hierarchy, paragraph spacing, line spacing, indentation, page dimensions, background, master/layout and geometry. Inspect representative cover, content, table/chart and ending images. Record a concrete style specification rather than guessing from a style label. Keep references read-only; Word reference learning must not overwrite the project's default profile. Identify inherited, unknown and truncated information.
3. Compose read, locate, local text edit, typography, background/shape style, geometry and page structure primitives. Use observed identities and expected original text; refresh page order after structural edits. Never replace globally for one local change. A failed operation may have created content: read back before retrying.
4. Apply consistent palette, hierarchy, grid and margins. The supplied reference takes precedence over defaults. Adapt Word hierarchy and visual identity to slide reading while preserving clear, readable grouping. Whitespace must support comprehension; meaningful evidence and organization take priority over decoration.
5. Read back content and inspect actual rendered images for every output page. Compare reference and output images when applicable. Check clipping, overlap, contrast, alignment, excess whitespace, fragmentation and chart clarity. Re-render and inspect affected pages after fixes. Only inspected images count as visual verification; tool success or text extraction is insufficient. Disclose unavailable capabilities and unchecked pages. Fix visible clipping, overlap and material style mismatches. Optional polish must not trigger endless full-deck revisions or repeated checks of pages already verified.

When generating a PPT from a Word reference, finish learning the reference, then call slide_create_file to create and open the output BEFORE discovering other slide_* tools. Those tools are hidden while Word is active and become available after creation; repeated catalogue searches cannot reveal them before the switch. This is not missing capability and is not a reason to switch to image generation.
