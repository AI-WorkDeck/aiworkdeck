# 演示文稿制作与样式参照

本技能提供可组合的制作步骤，不限制其他任务工具；使用当前宿主实际提供的原语，不假设各宿主能力相同。

1. 理解读者、用途、核心结论与证据。优先利用已有资料，不虚构事实，不为凑页数扩写。先把相关信息分组：同一论点和证据在同页，对照信息并列，时间关系用时间轴，复杂数据用表或图。页数由阅读需要决定，避免一个短句一页；高密度不是把字缩小。信息较少且相关的时间线、风险与决策可合并组织，不为维持卡片布局摊成多页。资料中的合成、假设或示例性质须在相关结论和数据页上清楚可见，不能只写在备注里，也不能表述为真实实测结果。
2. 有参考文档先学习。结构上读字体字号、粗细、标题层级、段前段后、行距缩进、页尺寸、背景、母版布局和形状几何；视觉上查看代表性的封面、正文、表图与结尾。形成具体样式清单后再制作，不凭“商务风”等标签臆测。只读参考，学习Word不得覆盖项目默认画像。继承值、未知值和截断范围明确记录。
3. 从Word参考新建PPT时，先完成参考学习，再调用 slide_create_file 新建并打开输出文件，然后读取页面和展开其他 slide_* 工具。当前活跃文档仍是Word时，其他 slide_* 工具会按文档类型隐藏；反复搜索找不到不代表能力缺失，也不应改走图片生成。
4. 组合独立能力：读取、定位、局部改字、文字格式、背景和形状样式、几何、页结构各自完成。先用读回的身份和原文定位；结构调整后更新页码，不复用旧位置。新建页后先读取已有形状；自带标题或占位符应复用，或按准确身份明确删除后再创建替代内容，不能叠放第二份标题。只改一处就不全局替换。失败可能已产生部分内容，先回读再继续，不重复造页。
5. 建立统一配色、标题层级、网格与边距。参考样式优先于默认主题；从Word转PPT保留层级和视觉身份，按投影或阅读用途调整字号与分组。留白服务阅读；正文页应有足够依据和可读的组织，不用装饰掩盖内容空洞。
6. 完成后读取内容，并检查实际渲染的所有输出页；有参考时把双方图片对照。核对文字截断/重叠、对比、对齐、异常空白、信息碎片化、图表说明和参考一致性。修正后重新渲染受影响页面再检查。只有实际检查过的图片才能算视觉验证，工具成功或文本正确都不替代它；能力不可用时诚实报告剩余范围。必须修正可见的截断、重叠和关键风格偏差；可选润色不应触发无休止的全稿重做，已通过的页面不反复检查。每次修正须对应明确未达要求的问题；这些问题解决且受影响页面复核通过后即交付，不因可选建议继续增加微调轮次。

## 有表现力的设计

先根据主题、读者和已有品牌决定视觉方向，再选构图。不要把所有主题都做成深蓝卡片网格；在统一色彩、字级与节奏下，组合全幅或半幅出血图、非对称分栏、大数字、图表与注释、紧凑对比表、时间轴等。相邻页面应有节奏变化，不能机械地每页换风格。正文页仍须保留结论、证据和必要解释。

图片是独立素材，正文、数字、图例和数据表保持可编辑。可让图片或装饰形状越过画布边缘，按画布有意裁切；重要人物、产品主体与文字须留在可见区域。背景图应预留文字空间，并按实际明暗添加遮罩或纯色承托，避免繁杂纹理压住正文。先确定画面用途、比例、主体位置、留白方向、色调与裁切方式，再调用当前可用的生图工具；只生成需要的素材，不用整页图片代替可编辑演示文稿。已有合适图片优先复用，生成内容不得伪装成真实事件照片或数据证据。

按数据关系选择图表：类别比较用柱形或条形，趋势用折线，构成用堆积或少类别环形，相关性用散点；精确查值用表格。统一单位、量级和系列颜色，交代来源与必要基线，不虚构数值、不用装饰性三维效果扭曲比较。原生图表优先；工具未提供的类型不能声称已创建。

翻页过渡服务于叙述节奏，通常统一使用短而克制的过渡，在章节转折处再变化。参考有明确动效或用户要求时遵循；不默认逐页自动播放，不把所有对象都加动画。静态导出不含动画效果，必须分别核验保存重开和实际播放，不能拿PDF截图声称动画通过。

视觉复核区分有意出血与错误溢出：装饰或图片在画布边缘裁切可以成立；正文、数据标签、图例、关键主体被截断仍须修复。将插入后的图片与源图对照，确认主体仍可辨识、比例和画面内容未损坏；拉丝、条纹、马赛克或整图被裁空不能当作出血设计通过。检查整套设计是否呼应内容、是否过度重复卡片、是否有清晰视觉焦点，并核验数据、单位和可编辑性。生图失败时保留已经完成的页面，明确缺少的素材，不用无关占位图冒充完成。

能力可用时，每份计划素材只调用一次 image_generate_asset，使用稳定的 requestKey，再用 generationId 调用 image_get_generation 查询完成状态。完成后把返回的 db_id 交给 slide_add_image；查询或插入失败不意味着需要重新付费生图。先读取画布尺寸，明确 cover/contain、focalX/focalY 裁切焦点，并把背景图置于可编辑内容后方。原生数据用 slide_add_chart，配色与标签字号用 slide_format_chart，翻页过渡用 slide_set_transition；这些操作可分别与文字、形状和表格组合。部分失败后先读回目标页，再决定重试。
