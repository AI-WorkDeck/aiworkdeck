# 演示文稿制作与样式参照

本技能提供可组合的制作步骤，不限制其他任务工具；使用当前宿主实际提供的原语，不假设各宿主能力相同。

1. 理解读者、用途、核心结论与证据。优先利用已有资料，不虚构事实，不为凑页数扩写。先把相关信息分组：同一论点和证据在同页，对照信息并列，时间关系用时间轴，复杂数据用表或图。页数由阅读需要决定，避免一个短句一页；高密度不是把字缩小。
2. 有参考文档先学习。结构上读字体字号、粗细、标题层级、段前段后、行距缩进、页尺寸、背景、母版布局和形状几何；视觉上查看代表性的封面、正文、表图与结尾。形成具体样式清单后再制作，不凭“商务风”等标签臆测。只读参考，学习Word不得覆盖项目默认画像。继承值、未知值和截断范围明确记录。
3. 从Word参考新建PPT时，先完成参考学习，再调用 slide_create_file 新建并打开输出文件，然后读取页面和展开其他 slide_* 工具。当前活跃文档仍是Word时，其他 slide_* 工具会按文档类型隐藏；反复搜索找不到不代表能力缺失，也不应改走图片生成。
4. 组合独立能力：读取、定位、局部改字、文字格式、背景和形状样式、几何、页结构各自完成。先用读回的身份和原文定位；结构调整后更新页码，不复用旧位置。只改一处就不全局替换。失败可能已产生部分内容，先回读再继续，不重复造页。
5. 建立统一配色、标题层级、网格与边距。参考样式优先于默认主题；从Word转PPT保留层级和视觉身份，按投影或阅读用途调整字号与分组。留白服务阅读；正文页应有足够依据和可读的组织，不用装饰掩盖内容空洞。
6. 完成后读取内容，并检查实际渲染的所有输出页；有参考时把双方图片对照。核对文字截断/重叠、对比、对齐、异常空白、信息碎片化、图表说明和参考一致性。修正后重新渲染受影响页面再检查。只有实际检查过的图片才能算视觉验证，工具成功或文本正确都不替代它；能力不可用时诚实报告剩余范围。必须修正可见的截断、重叠和关键风格偏差；可选润色不应触发无休止的全稿重做，已通过的页面不反复检查。
