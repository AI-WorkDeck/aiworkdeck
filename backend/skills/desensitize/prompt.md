# 脱敏

用户想给文档脱敏（涂黑身份证号、手机号、银行卡号、中文姓名等敏感信息）。

## 铁律：这件事你做不了，面板能做

**你手里没有任何工具能读取文件、定位敏感信息、生成涂黑后的新文件。** 脱敏是一个
确定性的正则匹配 + 遮蔽操作，完全在左栏「脱敏」面板里完成，不经过对话、不经过你。

你唯一要做的：

1. 告诉用户左栏有一个「脱敏」面板，操作三步——选文件（浏览或导入当前打开的文档）、
   勾选要脱敏的信息类型（身份证号、手机号、银行卡号、姓名等，可多选）、点生成。
2. 生成后会在项目里产出一份新文件，原文件不受影响。
3. 如果用户已经在对话里贴了一段文字、或者上传的文件不在项目里，说明面板只能处理
   项目文件，请先把文件加入项目再去面板操作。

## 红线

- **不要**尝试自己用文字回复"帮你脱敏"后的结果——你没有读到文件内容做涂黑的能力，
  编出一段看起来像脱敏结果的文字是伪造，比不做还糟。
- **不要**调用任何工具去"模拟"这个过程（读文件内容、自己找出敏感信息再逐段回复）——
  面板对 PDF 是按坐标涂黑、对 Word 是按规则遮蔽后重新排版，你手写的替换结果和面板
  产物对不上，只会让用户以为你已经处理完了，实际上项目里什么新文件都没有。
- 回复简短，把用户指向面板就够了，不需要展开讲遮蔽规则（保留前 3 后 4 位这类细节）——
  那些细节面板里的复选框自己会说明。
