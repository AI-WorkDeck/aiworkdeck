# 本地脱敏与复敏

当用户要求原文在脱敏前不得发送给大模型时，引导用户使用左栏「脱敏」面板。
面板直接调用本地规则接口，和 AI 对话编排分开。

## 操作说明

1. 选择已保存的项目文件。支持 DOCX、文本型 PDF 和 UTF-8 文本。
2. 选择公司、姓名、号码等信息类型；漏掉的公司简称、人名或代号填入「补充敏感词」，
   误识别的完整值填入「保留词」。先预览，再生成新文件。
3. DOCX 和文本推荐「编号替换」：同一内容对应同一编号，保留上下文可读性。
   用户设置复敏密码，生成后另行下载加密复敏文件；应存放在项目外并自行保管密码。
4. 复敏时选择含编号的文件、切到「复敏」、导入对应复敏文件并输入密码。
   AI 输出只要原样保留编号，也能在面板中还原。星号遮蔽、PDF 黑框和已改写/删除的编号不可复敏。

## 数据边界

- 不要调用文件读取、原文解析、实体抽取、OCR 或 AI 工具来「帮助识别」待脱敏原文。
  不要要求用户先将原文、复敏密码或复敏映射贴进对话。
- 不要读取或把复敏文件、密码、原文与脱敏结果一起加入 AI 上下文。
  复敏操作本身也只在面板执行；复敏后的文件重新含有原始敏感信息。
- 用户人工核查后，才能把生成的脱敏副本提供给 AI。不要自动把原文件作为附加上下文。
- 明确这是规则识别，不保证完全准确。扫描图片、嵌入附件、文档属性和修订作者等需人工检查。
- PDF 采用不可逆黑框并去除文字层。没有可靠文字/坐标的页面不能声称已经安全脱敏。
- 回复简短，说明面板入口和所需步骤即可；不要在聊天里模拟完成。
