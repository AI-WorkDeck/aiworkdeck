# 系统保存框取消调查（dev-board #1564）

日期：2026-10-28；执行者：Codex 原生子代理 native_dialog。主任务另行核验新脱敏流程。

## 用户报告与代码路径

用户报告：脱敏后出现 `.awd-recovery` 系统保存框，关闭后整个工作台不可点击。

旧路径为 `DesensitizePane.downloadKit` → 插件 `sensitive/download` → `PluginPane` 的 `actions.download` 创建下载链接 → `desktop/main/main.js:attachDownloadListener` 为下载项设置 `setSaveDialogOptions`。`export-download.reportDownloadDone` 对完成、取消、失败均回报。已检查的项目代码未找到这条路径自行调用 `setEnabled(false)` 或 `setIgnoreMouseEvents(true)` 的行为。

## 本机隔离实测

使用现有 Electron 30.5.1（Chromium 124.0.6367.243），独立 home、appData、userData、sessionData、logs、crashDumps 与 temp；不启动后端、不使用个人账号或项目。为便于原生 UI 工具精确选择测试进程，临时复制 Electron.app 并只修改测试副本 bundle identifier/name。探针为隐藏原生标题栏的 BrowserWindow，内含按钮与 webview；点击下载的同时更换 webview 的占位编辑器页面。

实际通过原生 UI 工具点击系统“取消”，再点击页面按钮（含真实鼠标坐标），计数从 0 → 1 → 2。再次打开保存框并按 Esc，真实鼠标点击计数变为 3。主进程日志为：

```text
will-download test.awd-recovery
state false false 0
done cancelled enabled true focused true
post {"clicks":0,"focus":true,"active":"BUTTON"}
state true true 1
state true true 2
will-download test.awd-recovery
state false false 2
done cancelled enabled true focused true
post {"clicks":2,"focus":true,"active":"BUTTON"}
state true true 3
```

`state` 的前两项分别为 `BrowserWindow.isEnabled()`、`isFocused()`。系统 sheet 显示时禁用父窗口、取消后恢复，在本探针里正常。第二次切换同一占位 webview URL 时另有 `ERR_ABORTED`，但未阻止取消后点击。没有把该异常当成用户问题的根因。

既有回归命令：

```sh
node --test desktop/tests/recovery-download.test.js desktop/tests/pdf-export-download-dir.test.js
```

结果：13 项通过，0 失败，0 跳过，含 cancelled 下载回报。

## 复现探针

将以下内容保存到临时目录的 `probe.cjs`，使用本仓已安装的 Electron 执行：

```sh
./desktop/node_modules/.bin/electron /absolute/temporary/path/probe.cjs
```

只操作标题为 `AWD Native Dialog Probe` 的独立窗口；点击 Download → 系统取消 → Click count，重复 Download → Esc → Click count。测试后关闭探针窗口。没有自动操作真实客户端。

```javascript
const { app, BrowserWindow } = require('electron')
const fs = require('node:fs'), os = require('node:os'), path = require('node:path')
const root = fs.mkdtempSync(path.join(os.tmpdir(), 'awd-native-dialog-'))
for (const key of ['home', 'appData', 'userData', 'sessionData', 'logs', 'crashDumps', 'temp']) {
  const dir = path.join(root, key); fs.mkdirSync(dir); app.setPath(key, dir)
}
app.whenReady().then(async () => {
  const win = new BrowserWindow({ width: 900, height: 650, title: 'AWD Native Dialog Probe',
    titleBarStyle: 'hidden', webPreferences: { webviewTag: true, backgroundThrottling: false } })
  win.webContents.session.on('will-download', (_event, item) => {
    item.setSaveDialogOptions({ title: 'QA recovery save', defaultPath: path.join(root, 'test.awd-recovery') })
    item.once('done', (_event, state) => console.log('done', state, 'enabled', win.isEnabled(), 'focused', win.isFocused()))
  })
  const html = `<h1>Isolated recovery download cancellation</h1>
    <button onclick="const a=document.createElement('a');a.href='data:application/octet-stream;base64,QVdELVJFQ09WRVJZLTE6ZHVtbXk=';a.download='test.awd-recovery';document.body.appendChild(a);a.click();a.remove();setTimeout(()=>document.querySelector('webview').src='data:text/html,Simulated newly opened editor',1)">Download</button>
    <button onclick="this.textContent=++window.clicks">Click count</button>
    <webview style="width:800px;height:400px" src="data:text/html,Initial editor"></webview>
    <script>window.clicks=0</script>`
  const source = path.join(root, 'probe.html'); fs.writeFileSync(source, html)
  await win.loadFile(source)
  win.on('closed', () => app.quit())
})
```

## 证据边界与决定

本探针**未复现**用户的全窗口锁死。它验证了系统保存框在独立 Electron 中的取消/恢复行为；webview 内容是合成占位页面，未装载真实 LOWA，也未跑完整工作台/插件业务桥。初始 blob 探针因本探针环境 `URL.createObjectURL` 不可用未到达下载，随后改用合成 data 下载，不能声称复现了产品 blob 的所有时序。

因此没有凭猜测向桌面公共下载层增加 `focus()`、`setEnabled(true)`、关闭窗口或释放全部遮罩。主任务将脱敏恢复材料改为项目内保存、取消系统下载入口，可消除用户这条操作中的原生 sheet 触发；这不等于已证明所有系统文件框取消后的冻结原因，也不能替代完整工作台新流程验证。Windows 与正式签名客户端未测。
