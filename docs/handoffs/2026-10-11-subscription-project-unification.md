用户于 2026-10-11 要求跨官网、桌面、云后端、手机与插件统一推进，并为 Grok 下周接续保留记录。台账：dev-board #1187（计费）、#1188（项目）、#1189（官网）、#1190（移动）。本次只开发、验证及合并；没有发版或部署授权。

## 用户已确认与实施假设

已确认三档方向：原充值与按需解锁、149 元订阅、独立部署。订阅包含无线剪贴板、文件暂存区、3GB 持久云存储及周/月额度。免费 200MB 是同时临时占用上限，非月流量；取件确认后释放。

额度数值尚待用户答复。本次先实现每 30 天 149 Credits、每 7 天 45 Credits，按订阅周期开通时刻锚定，周期末结束最后一周，不结转。数值是保守初值，不是已确认的用户定价。三档备选已向用户提出：149/45、300/90、745/200。订阅与现金分账；超额默认不扣充值余额，用户可自行开启。临时中转池与持久池分别计量，所有账户临时池为 200MiB，Pro 持久池 3GiB；界面沿用 MB/GB 标签。

## 成本测算

代码现有充值语义：国内站 1 元 = 1 Credit；AI 默认按上游采购成本乘 1.2 折算扣费。各外部服务须按具体价目和真实汇率计算，以下只作默认 1.2 加成下的敏感性分析，不是利润保证。

| 每周期赠送零售 Credits | 用满对应采购成本 | 149 元减采购成本 | 不计其他成本的平均使用率盈亏点 |
| --- | ---: | ---: | ---: |
| 120 | 100.00 元 | 49.00 元 | 149%（用满仍有余量） |
| 149 | 124.17 元 | 24.83 元 | 120%（用满仍有余量） |
| 300 | 250.00 元 | -101.00 元 | 59.6% |
| 745 | 620.83 元 | -471.83 元 | 24.0% |

采购成本 = Credits × 实际使用率 ÷ 1.2。假设每名订阅用户还需要 H 元支付、存储、带宽和运维成本，则盈亏平衡使用率 = (149 - H) × 1.2 ÷ 周期额度。周限只能摊开消耗，不能消除满额使用的亏损。充值余额、订阅收入、赠送服务价值和真实供应商成本必须分别记录，不能将赠送 745 Credits 记成收入 745 元。

上述官方页面没有提供订阅可消耗 token 的固定总数，所以无法据此得出「20%」或「五倍」这个统一兑换比例。若要实测，需要对同一模型、输入/输出/缓存 token 和上下文复用方式保留完整用量，再按对应 API 当日价累计；调用次数不等于 tokens，API 零售价也不等于模型厂商自身推理成本。我们的 1.2 加成与额度档位是本产品经营口径，不冒称对标某家官方比例。

### 可复算的 token 情景示例（不是订阅额度承诺）

取每次 10 万未缓存输入 token + 1 万输出 token 的标准 API 请求，不计工具费和长上下文附加价：GPT-5.4 按输入 $2.50 / 百万、输出 $15 / 百万，约 $0.40 / 次；Claude Sonnet 5.5 按 $2 / 百万与 $10 / 百万，约 $0.30 / 次。若用 $20 订阅费作分子，要得到“订阅费 / API 等值 = 20%”，实际月用量必须达到 $100 API 等值，即分别约 250 次或 333.3 次上述请求。官方没有保证订阅能够完成这些请求量，因此这只是反推条件，不能据此给本产品五倍赠额。

标准价格来源（读取于 2026-10-11）：https://developers.openai.com/api/docs/models/gpt-5.4 与 https://platform.claude.com/docs/en/models/sonnet-5-5/overview 。缓存会显著改变等值金额；GPT-5.4 示例每次输入低于该页长上下文加价阈值。选择这两个 API 仅为演示算式，不表示订阅固定使用这两个模型。

## 接续检查

接续先核对三仓 Git、PR 与本台账，勿直接部署。官网过去的 Pro 已有真实微信一次性付款及 30 天权益落库；本次补额度和附赠功能。保留旧支付 SKU、回调幂等和预续费，不把它误写成自动续费。周期额度使用与失败退款要回原周期原周，不变成现金；Pro 订单退款本身仍沿用既有业务，本次没有新建退款支付通道。

统一项目以 projectUid 识别，旧 deviceId + projectKey 继续作为路由别名；不按名字合并。文件沿用 ProjectFile.uid；文件可以在本机、其他桌面或云端，取件仍走明确存储位置。旧上传重试已锁定的归属不可重写。同一项目既有桌面原件又有插件云附件时，必须能选择存储位置。

## 实现范围与已知边界

- 官网：独立订阅周期/周额度账，旧 Pro 订单幂等补期，默认不自动扣钱包；原调用授权、转写预占及失败退回保留原周期。三档中英文页面主推 Pro，真实购买入口维持一次性 30 天支付。
- 桌面与云：逐项权益到期，账户指纹隔离；临时中转与持久空间分开。普通上传、编辑、复制、模板、AI 产物、删除都纳入配额校验。项目删除失败保留记录；新副本事务回滚清理时重新取用户锁并验证没有新文件引用，避免误删同名重试结果。
- 项目：统一目录以本人拥有项目、桌面目录与插件归档位置为范围；团队受邀项目继续走原案件库成员权限入口，没有宣称共享团队权限已全部统一。离线文件目录来自最近一次成功 LIST，在线按需刷新，不持续扫描整台设备。
- 移动：iOS、Android、Harmony、小程序使用统一目录和旧别名兼容；四端独立显示订阅服务额度。iOS 在现有工作区中支持云/桌面位置切换和取件；其余三端没有在本轮新增完整文件工作区。持久用量接入 iOS、Android、Harmony 原有用量区，小程序原无该区。
- OpenRouter 仍是用户子 key 直连及累计用量回抄：已固化限额授权时的资金来源，跨周/月/到期不直接改扣当期或钱包；但供应商在限额切换瞬间仍在执行、稍后才计入累计用量的请求无法逐笔确定归属。不能把当前实现描述为所有 AI 请求即时、绝无超额的硬限。若需要这一保证，须将请求统一经服务端预授权计量，不能只改赠额数字。
- 尚未验收真实生产支付、真实订阅账户、云端双设备取件、Windows/macOS正式新包或 Harmony 原生构建。本轮隔离测试不触碰个人账户/资料，也没有部署或升级正式客户端。
