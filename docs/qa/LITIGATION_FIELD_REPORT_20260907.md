# 2026-09-07 诉讼可视化实测修复

对应开发看板：A4 #477、B11 #491、B12 #492、C12 #494、C13 #495。

## 修复与复测

### A4：旧资源包缺少时间轴入口

用户本地资源包为 2026-08-20 的 1.0.1，仅包含 doctor / validate / checkpoint / render，调用 timeline 时 argparse 直接退出 2，尚未读取材料。应用版本更新不会自动替换已安装资源包。

现于读材料前检查时间轴 pipeline 模块，保留退出码与有界 stderr 诊断，提示更新并保留语义地图回退。面板更新入口及新增不可用提示均有中英双语。已发布资源包的最高版本为 1.1.0；本轮包含 CLI 兼容修复的资源包应发布 **1.1.1 或更高版本**，继续经过既有签名与校验流程。

复测：旧包进入事实时间轴时应明确要求更新；语义地图仍可使用；更新完成无需重启面板。

### B11：手工改图后换风格静默覆盖，旧画布可能再次回写

手工保存原先未更新实体 updatedAt，而 handEdited 依赖该时间戳；原来的刷新事件也没有订阅者。改为每次换风格都明确确认覆盖当前手工修改，后端默认拒绝未确认的请求，且要求项目写权限。取消时没有文件读写、广播或编辑器暂停。

确认后暂停新保存，等待编辑器已接受的保存队列完成，再重画。成功后打开的画布重新读取文件（禁用下载缓存）；失败则保留原画布和未保存标记并恢复保存。普通保存仅刷新图廊，不重载正在编辑的画布。保存/重画更新时间用于图廊提示，不再作为覆盖授权。

复测：改节点与边文字后，换风格先取消，文件和画布必须保持；再确认，画布应自动变为重画结果。保存进行中确认重画时，必须先落盘当前保存再重画。

### B12：保存 PNG 只剩形状

原 draw.io SVG 在 switch 中同时带 XHTML foreignObject 和正确的 SVG text 后备。Batik 选择前者但不会绘制 XHTML，造成文字区域墨迹为 0。栅格化时仅在内存中移除有 SVG 文字后备的 foreignObject，保留已有文字、坐标和随包中文字体兜底；磁盘 SVG 母版不改。无法安全转换时不生成空文字 PNG，且保留上一版 PNG。输出先写临时文件，成功后才替换原 PNG。

真实原 SVG 只读验证：原 PNG 为 **20,466 字节**；修复转换后为 **82,962 字节**。已打开新 PNG 检查，中文标题与所有节点文字正常。转换前后原 SVG 的 SHA-256 一致。原项目文件未修改，检查产物留在持久工作树的忽略目录。

复测：在 draw.io 修改并保存，项目同子目录 PNG 应包含标题和节点文字；转换失败时旧 PNG 应仍在。

### C12：PNG 导出默认名缺少图名

嵌入 load 消息补入原 .drawio 文件名，draw.io 的原生导出对话框可据此生成 PNG 默认名。原生“导出为 PNG”的位置选择仍沿用 draw.io；应用内普通“保存”本来就会把 .drawio / .svg / .png 写回项目同子目录，不改变用户选择的导出比例与范围。

复测：打开有名称的图形，导出为 PNG 的默认名应含图名。

### C13：关系边说明未显示

真实旧地图的 12 条边使用 title，渲染器读取 label，导致原 SVG 和 drawio 边文字为空。新版 schema 还会拒绝旧地图的 edges.id、布尔 accent 和 nodes.subtitle。

在自有 CLI 包装层，对 graphviz_relation 做确定性的兼容转换：title → label、subtitle → note、布尔 accent → emphasis；剥离渲染器不使用的字符串 edge.id。仅生成临时副本，不改变用户源 JSON。显式规范字段优先，空 label 和 false emphasis 也保留；非布尔 accent 不猜测含义。原有 emphasis 来源/确认检查继续由引擎执行，不修改 vendor。

真实旧地图重新出图验证：**12/12 条 drawio 边均有文字，逐字等于源 title**；原地图前后 SHA-256 一致。合成回归同时验证 SVG、drawio 中的边说明/主体注释、规范字段优先、源文件字节不变。

复测：资源包更新后，对旧关系图确认重画，检查边文字与主体注释；新图也应保留模型提供的边说明。
