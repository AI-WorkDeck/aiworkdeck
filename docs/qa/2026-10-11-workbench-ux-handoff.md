## 确认的根因

- 本机目录点击原来仍等待云端 LIST（最长90次轮询），忙状态锁住所有项目。现在优先使用本地代理核验的 localProjectId；禁止按项目同名猜身份。
- 用户本地报错日志指向不存在的 `/api/tmeet/auth/login`，控制器实际为 `/auth/login-start`。状态 `loggedIn/userName` 被错当 `authorized/accountName`；`/sync` 是 query 参数；两个 prompt 端点是 POST 且返回 `data.prompt`。
- 旧 question 无选项时只有“在对话中回答”提示；模型提示也未把普通/插件的提问呈现统一成强约定。现在保留工具与模式权限，不从任意正文猜授权卡。
- 原文件记录只有会话级文件名/动作，无法可靠分轮。PDF 派生工具也可能把输入文件误认为新增。新增可空 fileId/projectId/assistantMessageId，旧数据保留独立历史入口，不倒灌到新轮计数。
