# 发布视频 AI 空镜（B-roll）批量生成工具

对应 dev-board #59，方案见上级目录 `broll-plan.md`。全片 34 分钟里只有约 75 秒
氛围空镜需要 AI 生成，成本在 10 元量级。产品画面一律真实屏录，绝不用 AI 生成
冒充产品界面。

## 三条硬红线（法律行业观众尤其敏感，写提示词与验收时都要守）

1. **画面里不许出现可读文字**。AI 生成的中文字必然是乱码，一个文件特写就穿帮。
   本工具默认 `watermark: false`——连官方水印也不要，因为水印本身也是一段文字。
2. **不许出现可辨识的正面人脸**。只用手部、背影、剪影，避免人物一致性差与肖像
   争议。
3. **不许用 AI 画面冒充产品界面或真实案件场景**。产品画面一律真实屏录，这个
   工具不碰产品界面相关的任何镜头。

生成出来的每一条素材，剪辑前先按这三条肉眼过一遍再入片。

## 怎么拿 ARK_API_KEY

方舟视频生成接口走 **Ark API Key**（Bearer 鉴权），跟 `.agent/ACCOUNTS.md` 里
记录的火山引擎账号级 AccessKey/SecretKey 是两回事，本工具不读、也不需要那个。

1. 登录 [火山方舟控制台](https://console.volcengine.com/ark)。
2. 「系统管理 -> API Key」，新建一把 Key。
3. 本地设置环境变量（不要写进任何文件、不要贴进对话）：
   ```bash
   export ARK_API_KEY=你的key
   ```

## 怎么跑

```bash
cd docs/marketing/launch-video/broll

# 先 dry-run，确认请求体和成本预估符合预期，不消耗任何额度
node generate.mjs --all --dry-run
node generate.mjs --shots A1,B2 --dry-run

# 确认无误后，正式生成
node generate.mjs --shots A1          # 只生成 A1
node generate.mjs --all               # 生成全部（自动跳过 D 组未填写提示词的预留位）
```

无需 `npm install`——只依赖 Node 18+ 内置的 `fetch`，没有第三方依赖。

产物：
- `out/{镜头id}-{时间戳}.mp4`：生成的视频文件。
- `out/manifest.json`：每次运行都会追加记录，包含每个镜头的提示词、模型、
  分辨率、任务 id、耗时、token 用量与成本。
- `out/` 目录本身已加入 `.gitignore`，不入库。

并发限额固定为 1，脚本内部严格串行，不要并行起多个进程同时跑，否则接口会拒绝。

## 成本口径

- 火山方舟按 token 计费：`token = 宽 × 高 × 24fps × 秒数 / 1024`，单价
  4.2 元/百万 token。
- `--dry-run` 用标准 16:9 分辨率像素数（720p=1280×720，1080p=1920×1080）预估，
  与 `broll-plan.md` 第四节已用官方口径校验过的数字对齐（1080p/5秒=243,000
  token≈1.02元）。
- 正式生成完成后，`manifest.json` 里的成本以 API 返回的 `usage.total_tokens`
  为准（更准确），预估表只在 API 未返回 usage 时兜底。
- 每次运行结束会在终端打印本次总成本。

## 建议流程：先用即梦免费额度试质量，再决定是否上 seedance

按 `broll-plan.md` 第四节的结论，即梦 AI 的图片生成与视频生成（3.0 Pro 1080P）
控制台目前显示免费试用额度。推荐顺序：

1. 先在即梦控制台用免费额度，把 15 个镜头的首帧图和几个关键镜头（比如片头
   A1）的视频跑出来，肉眼验收是否满足三条红线、氛围是否到位。
2. 如果即梦免费额度出的效果已经够用，直接把首帧图路径填进 `shots.json` 每个
   镜头的 `firstFrameImagePath` 字段（相对或绝对路径均可，会原样作为
   `image_url` 传给方舟接口），跳过重新画图的成本。
3. 即梦额度用完或效果不够时，再用本工具批量走 seedance-1.0-pro-fast 出片
   （组 A/C 用 1080p，组 B 用 720p，与 `shots.json` 里的默认配置一致）。
4. 只有某个镜头（比如片头第一个镜头）用 1.0 pro fast 反复出不了满意效果，且
   该镜头确实关键时，才通过 `ARK_MODEL_ID` 环境变量单点切到 Seedance 2.0（单价
   贵 13 倍），不作为主力模型批量使用。

## 镜头清单

15 个镜头的完整中文提示词维护在 `shots.json`，按组别：

- 组 A（开场，冷调压抑，1080p）：A1-A4。
- 组 B（章节转场，冷暖抽象过渡，720p，生成 5 秒剪辑时裁到 3 秒）：B1-B5。
- 组 C（结尾愿景，暖调明亮，1080p）：C1-C4。
- 组 D（机动备用，预留）：D1-D2，提示词留空，等试映后再补，`generate.mjs`
  会自动跳过空提示词的镜头。

视觉母题统一为「纸与光」，呼应官网衬线、纸白的视觉体系。
