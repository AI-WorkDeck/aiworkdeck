# 发布视频 AI 生成镜头（B-roll）方案与成本

日期：2026-08-20。对应 dev-board #59。结论先行：全片 34 分钟里，**需要 AI 生成的画面约 75 秒**，成本在 10 元量级，不是 1800 元量级。

## 一、为什么不是 30 分钟

发布视频的画面构成（按脚本 v2.2 统计）：

| 画面类型 | 时长 | 来源 | 成本 |
|---|---|---|---|
| 产品真实屏录（第三章八幕、第四章、2.2 界面） | 约 26 min | CDP 录屏流水线 | 0 |
| 图卡与动效（章节页、定位句、定价卡、法律科技地图） | 约 5 min | HTML 渲染 | 0 |
| 摆拍屏录（冷开场多窗口地狱） | 1 min | 本机录屏 | 0 |
| 书封/目录 | 0.2 min | PDF 渲染 | 0 |
| **氛围空镜（B-roll）** | **约 1.2 min** | **AI 生成** | 见下 |

产品画面**绝不能用 AI 生成**——发布会上放假界面，在专业观众面前是灾难，也违背发布诚信。AI 视频在这支片子里只干一件事：**填补那些「拍不到、又必须有」的氛围镜头**，让长片不至于 34 分钟全是屏幕。

## 二、镜头清单（15 个镜头 × 5 秒 = 75 秒）

## 三、三条硬红线（法律行业观众尤其敏感）

1. **画面里不许出现可读文字**。AI 生成的中文字必然是乱码，一个文件特写就穿帮。所有镜头选取无文字的物件、光影、空间。
2. **不许出现可辨识的正面人脸**。一是人物一致性差（同一个「律师」在不同镜头长得不一样），二是避免肖像争议。只用手部、背影、剪影。
3. **不许用 AI 画面冒充产品界面或真实案件场景**。产品画面一律真实屏录。

## 四、模型选型与成本

火山方舟按 token 计费，视频 token = 宽 × 高 × 帧率 × 秒数 / 1024。已用官方口径校验：1080p/24fps/5 秒 = 243,000 tokens，doubao-seedance-1.0-pro-fast 单价 4.2 元/百万 token → 1.02 元，与官方公布的「5 秒 1080P 约 1.03 元」吻合。

| 模型 | 单价 | 5 秒成本 | 75 秒总成本 | 用途 |
|---|---|---|---|---|
| 即梦 AI 图片生成 | 控制台显示免费试用 | 0 | 0 | **产全部首帧图** |
| 即梦 AI 视频生成 3.0 Pro 1080P | 控制台显示免费试用 | 0 | 0 | 先吃免费额度，验质量 |
| doubao-seedance-1.0-pro-fast 720p | 0.091 元/秒 | 0.45 元 | **6.8 元** | 转场组 B（会被裁切/虚化，720p 够） |
| doubao-seedance-1.0-pro-fast 1080p | 0.204 元/秒 | 1.02 元 | **15.3 元** | 主力：组 A、组 C |
| Seedance 2.0 有参考 | 1.20 元/秒 | 6.00 元 | 90 元 | 仅备用（见下） |

**推荐配置**：首帧图走即梦免费额度 → 图生视频走 seedance-1.0-pro-fast，组 A/C 用 1080p、组 B 用 720p。含 3 倍废片重试的现实预算：**约 50 元**。

Seedance 2.0（1.2 元/秒）的定位：只在 1.0 pro fast 出不来满意效果、且该镜头确实关键（比如片头第一个镜头）时，单点使用 1-2 个镜头，增量成本 12 元以内。**不作为主力**——13 倍差价买不到 13 倍效果，何况这些是转场空镜。

并发限额均为 1，生成串行；pro fast 出 5 秒 720p 约 10 秒，15 个镜头连同重试半小时内可跑完。

## 五、接入准备（待维护者提供）

`.agent/CREDENTIALS.md` 里已录火山引擎 AccessKey/SecretKey（账号级），但方舟视频接口走的是 **Ark API Key**（Bearer 鉴权），需要在方舟控制台「系统管理 → API Key」新建一把，之后以环境变量 `ARK_API_KEY` 提供。密钥照规矩留在原位，不入库、不贴进对话。

接口形态（已按官方文档 docs/82379/1901652 核实，两处与初稿假设不符，以此处为准）：

- 创建任务 `POST https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks`，Bearer 鉴权；轮询 `GET .../tasks/{id}`，status 取值 `queued/running/succeeded/failed/expired`（不止两种），成功后取 `content.video_url`，并可用返回的 `usage.total_tokens` 核对真实计费；
- **模型 id 是 `doubao-seedance-1-0-pro-fast-251015`**（`-250528` 是不带 fast 的 pro 版，别用错，差价十几倍）；
- **分辨率/时长/宽高比走请求体顶层字段** `resolution`/`ratio`/`duration`（强校验），不是文本里追加 `--参数`；旧式文本参数名也是缩写 `--rs`/`--rt`/`--dur`，不是全称；
- `watermark` 显式设 `false`：官方水印本身就是一段可读文字，会撞红线一。
