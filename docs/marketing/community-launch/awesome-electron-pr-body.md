**Why it should be included**: AI WorkDeck is an open-source (AGPL-3.0) desktop workbench for lawyers and other document-heavy work, built by a practicing lawyer. What makes it distinctive as an app: the document editor is LibreOffice compiled to WebAssembly running inside the renderer (real .docx, tracked changes, comments, CJK/IME), and AI edits are applied only as character-level tracked changes the user accepts or rejects. It ships signed macOS and Windows binaries, has an English readme with a screenshot, is over 30 days old (first release May 2026, weekly releases since) and has 100+ stars.
