## 一、数据存在哪里

**问：律师的文件和 AI 对话存在哪里？**
答：默认存在律师自己的电脑上。桌面端的数据目录是 `~/.aiworkdeck`，项目元数据和 AI 对话存在其中的 H2 嵌入式数据库，托管项目的文件在 `projects/` 下；「打开本地文件夹」型项目的文件留在律师原来的文件夹（`desktop/main/awd-home.js`、`application-desktop.yml`）。

**问：什么情况下数据会上云？**
答：只有律师主动使用云功能时：插件云（Office/WPS 任务窗格的 AI）、案件库协作与客户门户、跨设备传输、手机影像中转、文件云端备份（默认关闭，需订阅并明确同意）、手机日程与个人助理、项目沟通 IM。逐项说明见 PRIVACY 第二节、第二之二节，保留期见 `data-retention.md`。

**问：云端数据在哪个国家？**
答：国内站在阿里云北京（服务器与 OSS cn-beijing）；国际站在新加坡（OSS ap-southeast-1）。两站数据库、令牌、案卷目录相互独立，国际站故障不会回落到大陆节点（`deploy/case/README.md`、`deploy/cloud/README.md`、PRIVACY 第二节）。

**问：本地数据加密吗？**
答：本地数据库和项目文件没有应用层加密，依赖操作系统磁盘加密（FileVault / BitLocker），建议律所统一开启。插件与连接器凭据单独用 AES-256-GCM 加密（`PluginCredentialStore`）。管理员填写的服务 Key 目前以明文存在本地数据库（`SystemSettingService`）。见 `data-classification.md`。

## 二、模型调用经过谁

**问：AI 请求发给谁？**
答：取决于律师在桌面端选择的通道（PRIVACY 第一节）：

| 通道 | 路径 | 是否经过 AWD 服务器 |
|---|---|---|
| 本地 Ollama | 只在本机处理 | 否 |
| 自备 Key | 本机直连律所自己签约的模型服务商 | 否 |
| 国内站「AI WorkDeck 云端」 | AWD 国内服务器 → 阿里云百炼北京接入点 → 所选模型 | 是。网关记录账户、模型、用量，不把转发正文写入计费日志或账本 |
| 国际站「AI WorkDeck 云端」 | AWD 服务器签发限权密钥；本机连接 OpenRouter → 实际推理供应商 | 正文不经 AWD 服务器，只做结算 |

注意：

- 百炼北京接入点不等于推理一定在中国内地完成，部分模型可能在境外处理。
- Office/WPS 插件、共享案件库、沟通助手、手机个人助理的 AI 请求从 AWD 云后端发出，按站点经百炼或 OpenRouter。
- 第三方供应商的留存和训练规则适用其各自政策，AWD 不承诺第三方零留存。

**问：AWD 用我们的数据训练模型吗？**
答：PRIVACY 写明平台代采的数据服务请求「不用于任何模型训练」，下一句建议、文档自动补全等功能「不会自动训练模型」。模型供应商侧适用其政策。【待确认】是否需要一条覆盖全部功能的统一表述。

**问：联网搜索、工商查询、法规检索等经过谁？**
答：默认「平台代采」档经 AWD 服务器透传给境内供应商（博查、企查查、Tushare、北大法宝、阿里云 OCR、听悟），除会议录音音频外不落盘、不写日志。每项都可改为「自备 Key」本机直连或「停用」（PRIVACY 第二节、第四节）。完整供应商清单见 `vendor-management.md`。

**问：有没有使用统计回传？**
答：「分享匿名使用统计」默认开启，每天一条聚合计数，可在「设置 - 数据统计」关闭。采集层有字段白名单，文档内容、对话文本、文件名、客户名称不会进入该通道（`TelemetryAttrWhitelist`，PRIVACY 第五至十节）。团队使用统计默认关闭，由成员本人开启。

## 三、如何自托管

**问：能否完全在律所内网运行？**
答：部分可以，需要逐项配置并验证（`README.zh-CN.md` 也这样提示）：

- **桌面端本身**：后端只监听本机回环地址；AI 选本地 Ollama 或律所自备 Key，平台服务逐项改为自备 Key、本地或停用，即可不经 AWD 服务器。
- **团队服务器（案件库）**：同一份 `backend.jar` 以 case profile 运行，PostgreSQL 14，部署方式见 `deploy/case/README.md`；桌面端通过 `CLOUD_COLLAB_BASE_URL` 指向自建服务器。团队自建服务器恒为自备 Key，不开放平台代采档。
- **从源码运行**：`docs/getting-started.md`。

**目前的限制（如实说明）：**

- 自建团队服务器的账户身份仍经 AWD 官网账户桥接（`awdk_` 登录），没有文档化的完全独立身份方案，也不支持 SAML / OIDC / LDAP 单点登录。【待确认】
- 桌面端界面中填写服务器地址的入口已移除，改连自建服务器需要配置项。【待确认】面向律所的操作说明。
- 默认仍会访问的外部地址包括：更新检查（www.aiworkdeck.com，备用 GitHub）、文档编辑器引擎 CDN（cdn.zetaoffice.net）、匿名使用统计（可关闭）。设置 `AWD_DISABLE_UPDATES=1` 可关闭自动更新。【待确认】完整的「离线/内网部署」出站清单与关闭方式。
- `deploy/case/README.md` 主要是 AWD 自己的北京/新加坡实例的部署记录，不是面向律所的通用安装手册。

## 四、如何删除数据

**问：律师离职或停用，怎么删除数据？**
答：

- **本机数据**：删除项目、会话，或直接删除 `~/.aiworkdeck` 目录。AWD 不能也不会远程删除律师电脑上的数据。
- **注销账户**：应用内注销（`POST /api/auth/account/delete`），删除云端中转媒体、传输记录、会话、设备令牌、账户绑定和账户记录，并同步删除官网账户。
- **云端会话、案件库项目**：在应用内删除会话或项目；云端项目由所有者删除。
- **项目沟通 IM 消息**：目前没有自动到期，需联系 hi@aiworkdeck.com。
- 详见 `data-retention.md` 第三节。

**问：删除后备份里还有吗？**
答：PRIVACY 已说明，运维备份与已发送给第三方的内容不等于在线数据库，不能承诺追溯删除全部副本。【待确认】服务端备份的现状与保留期（`data-retention.md` 第四节）。

答：私下发至 hi@aiworkdeck.com（`.github/SECURITY.md`）。目前没有承诺的响应时限。【待确认】

**问：有没有安全审计或认证？**
答：有内部审计记录（`docs/SECURITY_AUDIT_2026-08.md`）；没有第三方认证或渗透测试报告。【待确认】

**问：能否提供软件物料清单（SBOM）？**
答：可以。每次 CI 生成 CycloneDX 格式 SBOM（`asset-management.md`）。第三方组件与许可见 `legal/THIRD-PARTY-COMPONENTS.md`。

**问：代码是开源的吗？律所能否自行审计？**
答：是。AGPL-3.0 开源，仓库公开（github.com/AI-WorkDeck/aiworkdeck），另有商业许可（`legal/COMMERCIAL-LICENSE.md`）。

**问：安装包如何防篡改？**
答：macOS 安装包经 Developer ID 签名并公证，Windows 经 Azure Artifact Signing 签名；自动更新清单用 Ed25519 验签，组件按 sha256 校验（`change-management.md` 第三节）。

**问：数据出境？**
答：平台代采的六家数据服务全部在境内（PRIVACY 第二节）。AI 模型请求是否出境取决于站点和所选模型，见第二部分。【待确认】是否需要单独的个人信息出境评估说明。
