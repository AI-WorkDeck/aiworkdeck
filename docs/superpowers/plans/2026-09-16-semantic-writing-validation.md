# 语义写作首轮实现与验证（2026-09-16）

## 已接入的操作

在 Writer 的“语义补全”面板选择文种、项目写作立场、核查基准日和最多四份项目材料，可整理字段、续写当前句、续写一段或改写选区。建议带原文引用，点击采用才插入；一次撤销恢复。三类适配同时接入：起诉状/代理词、合同、尽调报告/法律意见。

- 当前实时正文与同项目显式选中的材料组成上下文。来源、主体、主张、条件、缺失、冲突各自保留；没有配置立场就不推定我方。
- 合同定义与字段遵循正文/附件、章节及当前文档范围；完整保留短段里的条件。超过边界或无法定位时停止局部推断。
- 生成走现有辅助模型及账户路由，真实 HTTP 可取消，输出/时间/并发/频率受限。没有服务端用量报告时费用状态为未知；不把取消说成免费。
- 普通输入沿用原有本地词语补全。此次新增生成均为手动；没有启用停笔自动云请求。
- 接受前后分别校验项目权限、材料版本、编辑版本、光标和选区；IME 在实际执行写入时再核对一次。

## 已明确的工程边界

当前正文最多16000字，选择材料每份前6000字、最多4份且每份8MB以内；界面提示截断。没有全项目语义索引。已验证的编辑范围是正文，表格/脚注/页眉等不能确切定位的范围不套用局部字段。模型请求预算25秒，建议上限当前句160字、一段600字、改写2000字。Ollama在本路径明确提示暂不支持，不会暗中转云。

来源/数值/已知语义规则校验可拦截已知错误，不能证明所有生成句均正确。正文与材料内容按非可信输入处理；模型不具备外部检索或写文件工具。

## 测试证据

- 前端324项通过（语义面板/host/API与已有补全、修订、relay、LOWA纯函数回归），H5构建通过。
- 真实LOWA引擎验证后缀、多段插入、选区替换、单步撤销/重做、位置/版本/只读失效、正文与附件范围。
- 真实guest面板验证引用预览、服务端给定文本接受、撤销、异步IME竞态、1280×800窗口及深色模式。截图使用清楚标注的合成后端响应；这与真实模型评测是两层独立证据。
- 后端188项专项检查通过。Qwen 3.7 Flash 的18个合成开发用例最新整轮17/18通过；一项供应商HTTP失败，单独重试通过。保留原失败，不拼接成单轮18/18。14次有用量返回的模型请求耗时中位数3.369秒（包含返回空建议），范围1.665–4.985秒；不是用户端完整链路P95。
- GPT-5.4请求遇供应商地区403，未形成质量对照。强制推理型号的兼容修正后，Qwen 3.8 Max 单例真实请求通过但耗时12.848秒；完整对照结果另见实现PR，不据此默认更换用户模型。实际模型案例仅为开发回归集，不能当95%泛化正确率证据。

## 实际评测发现并修正的问题

1. 仅推理而无正文的流结束未正确终结；现传输与服务端保证终态，保留供应商已报告用量。仅实测的Qwen 3.7 Flash写作请求关闭推理，其他型号保留默认行为，普通聊天请求不变。强制推理型号不能按供应商前缀一律禁用推理。
2. 长UUID引用被模型抄错；模型使用F1/F2短编号，返回时精确映射并重新验证真实来源，未知编号仍拒绝。
3. 已有“法院认定”前缀、先填无归属冲突金额再加“原告主张”等候选可能绕过只看后缀的校验；新增完整当前句反例。
4. 公司没有取得资质与项目组未取得材料被混淆；新增主语、材料状态、出具日与核查截止日的反例。
5. 原始未纳入范围的全文可能经source.text回流；模型只接收允许事实的完整引用。
6. 服务端等待期间开始输入法组合造成接受竞态；写入分发点读取实时组合状态。
