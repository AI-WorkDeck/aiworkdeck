# AI WorkDeck 产品发布视频设计 spec

日期：2026-08-20
状态：已与维护者讨论定稿（形式/观众/案由/时间线四项均已拍板）
产出物：约 33 分钟发布会式长片 + 3 分钟预告片

## 一、定位与叙事

- **主定位句**：律师第一次拥有了属于自己的工作台。
- **价值句**（结尾回扣）：让律师把时间留给判断。
- **传播句**（预告片/海报）：把整个案子，装进一个窗口。
- **片名**：《AI WorkDeck 发布——从历史困局到平台跃迁》，续接《大模型时代的法律科技——从历史困局到平台跃迁》一书，形成「著者即造者」叙事：先出书论证法律科技必须从工具孤岛走向平台，再亲手把论证做成产品。

### 从书中直接引用的金句（已核对前两章原文）

| 金句 | 用在 |
|---|---|
| 律师是「人肉总线」/「人肉适配器」 | 第一章开场痛点 |
| 「我们写的不是文件，是文件的第 15 版」 | 第七幕（版本管理）引子 |
| 「格式即信用、字体即专业、排版即能力」 | 第六幕（标准格式输出） |
| 「不是工具不好，而是工具无处安放」 | 第一章解释零散工具为何失败 |
| 「技术来帮律师砌砖，不是来替律师画图」 | 全片价值观句，回应「AI 替代律师」疑虑 |
| 技术成为律师桌上的「第二双手」 | 收尾意象 |

### 借鉴的发布会共性（乔布斯/雷军分析结论）

1. 先立「敌人」（行业现状）再出产品，痛点铺垫占足开场；
2. 重新归类而非罗列功能（「不是三个工具，是一个工作台」，对应 iPhone 三合一句式）；
3. Demo 是主角（demo 占全片一半以上）；
4. 一句话定位 + 少量金句；
5. 雷军式诚意结构：讲过程、讲人、结尾获取方式做成有释放感的时刻；
6. 情感弧线：Why → What → Demo → 生态 → 获取 → 愿景。

## 二、基本盘（已拍板）

- 形式：**纯屏录 + 维护者本人旁白**（不出镜）；
- 首要观众：律师/律所用户；兼顾投资人/行业、法律科技圈/开发者；
- Demo 主线：**劳动用工诉讼（员工侧，违法解除 + 关联公司混同用工）**；
  - 选型理由：受众理解成本最低（裁员潮后人人懂）；混同用工给企查查股权穿透一个「破案时刻」；生态里已有 HR 用工模板包插件可衔接生态章节；
  - 已否决：对赌回购（太难懂）、建工（行业下行）、婚姻家事（情感沉重）、民间借贷（可视化太薄）；
- 时间线：一个月出片（详见第六节）。

## 四、Demo 八幕与虚构案件

### 虚构案件事实（材料包按此起草，日期相对发布时点设定）

- 当事人：**林芳**（化名，产品经理，35 岁）；
- 用人单位：**星澜科技（上海）有限公司**（签合同）；关联公司：星澜网络科技有限公司（发工资）、星澜信息技术（苏州）有限公司（缴社保）——三家同一实控人，构成混同用工；
- 时间线：2019-03 入职签三年合同 → 2022-03 续签 → 2024-06 起工资改由星澜网络发放 → 2025-11 口头通知「岗位取消」 → 2025-12-31 强制离职、未付补偿 → 2026-01 微信记录（HR：「N+1 走不了，公司没钱」）→ 现在（2026-08）介入，仲裁时效 2026-12-30 届满，**窗口正在关闭**；
- 争点：违法解除赔偿金（2N）；三公司混同用工连带责任；加班费（钉钉打卡记录）；未休年假折算；
- 全部当事人、公司名均为虚构，材料包中显著标注「演示用虚构材料」。

## 五、生产流水线与分工

- 会话侧：逐字稿脚本与分镜表；虚构案件材料包（约 10 份文件）；CDP 驱动真实产品的自动化录屏（干净、可无限重录，复用 marketing-screenshots 流水线思路）；章节图卡（对齐官网 DESIGN.md：衬线、浅色、全程无 emoji，品牌名 AI WorkDeck 大写 D）；ffmpeg 粗剪（画面+旁白+字幕+配乐）；3 分钟预告片剪辑。
- 维护者侧：审脚本两轮；审案件材料真实性；按逐字稿配音（每段标注目标时长与断句）；定价与获取方式口径；试映反馈。
- 可选外援：粗剪后进剪映/FCP 人工精修一轮。

## 六、时间线（一个月）

- 第 1 周：脚本 v1 + 案件材料包 → 维护者审；
- 第 2 周：脚本 v2 定稿；搭录屏流水线，产出全部 demo 素材与图卡；
- 第 3 周：维护者配音；粗剪 v1；内部试映；
- 第 4 周：按反馈精修、剪预告片、择机发布（可与某个版本发布联动）。
