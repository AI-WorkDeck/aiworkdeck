# #1701 实施政策（2026-11-04 用户授权主任务定稿）

用户确认：当期赠额面值1:1授信，不随消费递减；超限停新增，首次超限72h提醒120h未付清清云端不动本机。用户进一步授权自行评估剩余事项并实施至PR合并。

定价：CNY存储0.20元/GiB/30天，USD0.03美元；出口0.60元/GiB、0.15美元/GiB。上传免费。按byte-seconds和bytes累计，整数账务单位与余数，不逐文件/请求最低取整。订阅3GiB抵扣；同段现有付费传输不重复计费。保留其他服务价格。价格版本固定于服务事件，不追溯计价。
授信：有效订阅当前周期monthlyLimitCents为基数；另有明确creditEligible标记且规定开始/结束的注册/活动赠额以original面值计入；充值、创作者分成、退款不算。无赠额零授信仍可预付使用。旧奖励不可自动转授信来源。订阅结束降低额度，债务保留；首次被动超限从额度生效时建立事件，不追溯。已有事件不能被部分付款/续订/调额重置；实际已结算债务付清或账务冲正证明无欠款才解除。授信内债务不另设月结日。
资金：旧请求仍按原授权；新后付费模式需明确接受，赠额→允许余额→授信。还款优先清偿债务，余款进钱包。历史shortfall不转用户债务。第三方广场商品和用户BYOK不因本次自动获得授信。
生命周期：超限停新增付费但保留读、还款、导出；授信不足的新任务不启动，已授权在途及存量存储可能导致超限。T+120停止用户存储计费。72h通知必须有可靠投递/持久站内告知记录；通知故障、支付核对中、归属不明时待复核，不擅删。
清理：仅官方云端本账户个人拥有资源。团队项目/他人所有资源不因个人欠费删除；归属未明确者冻结新增写入、待核对。个人所有但已分享的云项目本期同样转人工复核，不自动清除；须核对协作者的数据权属、付款责任和导出通知后另行处理，不能只凭创建者字段删除。保留账户/账单/债务/最小删除回执。不可复用注销或普通同步删除命令。逐批权威不可逆许可，已领取批次可能继续，支付取消后续批次；清理冻结期间暂停读取，待删除回执核对完成、债务结清并由用户明确恢复后，才恢复尚未删除内容的访问。云epoch防旧上传发布；清理后付清也不自动全量重传，明确重新开启备份。
合并边界：开发验证后合并，不发版部署、不开启生产清理。计费和删除独立开关；功能不能仅有空壳，实际入口、资金路径、计量、通知与保护均须验收。若经营规则的完整实现依赖尚不具备，则关闭对应危险能力并明确未完成，不标整个任务完成。

下载结算：每次HTTP尝试单独预占并绑定资源版本；只结算服务端成功写出的字节，不能宣称客户端已完整保存。断线后重新报价确认，不自动付费重试。欠费事件中每一资源版本提供一次成功免费导出，失败重试累计上限为完整大小三倍；超出转协助导出。清理开始可能有已领取的删除批次继续执行，付款不能恢复已经物理删除的数据。

计费范围：下载流量仅针对明确的文件、版本及Git/对象协议导出；普通应用API元数据、抽取文本和对比JSON流量包含在功能服务中，不另按流量收费。记忆文档迁移中的同源内容只计一次，自动派生的memory物化工作树不重复收费，Git历史存储仍按实际占用计量。旧项目未明确PERSONAL付款归属时不擅向创建者计费，暂停该项目新增写入并待归属核对，不因此冻结其他归属明确的个人内容。

恢复保护：云端执行器须在本地元数据事务提交后确认回执核对完成，账户站方可接受恢复；单有远端删除回执不足以恢复。手机旧上传队列转为手动恢复，桌面Git/记忆同步持久绑定已确认的云代次，重启不自动采纳新代次，用户明确重新连接才恢复。

提醒回执迟到：首次提醒确认在原T+120期限或之后才收到，转待复核，不自动新发删除许可；不能因刚补到回执就在同一轮删除。回执迟到不等于通知实际迟到，须核实证据。重复回执不改变首次判定；原T+120存储止费不延长，付清欠款仍可正常解决欠费事件。
