# 按量后付费：交付和运维边界

本文件配合[实施政策](2026-11-04-postpaid-cloud-policy.md)使用。合并代码不等于启用生产计费或清理。本次只使用隔离测试账号、临时数据库和临时文件，不执行生产支付、通知或删除。

## 开关与发布顺序

账户站 `AWD_POSTPAID_ENABLED` 控制接受新政策；`AWD_POSTPAID_CLEANUP_ENABLED` 单独控制清理资格。官方云端 `AWD_CLOUD_POSTPAID_ENABLED` 控制新能力与计量；`AWD_CLOUD_CLEANUP_ENABLED` 单独控制清理执行。上述开关默认关闭。桌面本地模式不得运行云端清理。`AWD_CLOUD_SAFETY_LIMIT_BYTES` 是容量安全上限，不是订阅资格或免费权益。

生产启用属于另一次明确授权。启用前先部署相互兼容的账户服务、云端服务和客户端，核对账户映射与站点币种，做影子用量与存量权益对账，再开放政策接受与计量。提醒和删除最后单独演练。不能仅开某一端的开关，不能通过手填会员状态绕过账务权威。

旧请求按原资金授权结算。存储从已接受政策和可信计量基线开始，不反推旧占用、不能补收通知前历史费用。无可靠历史基线时建立当前基线，不猜测过去容量。完整恢复后，用户需要明确开启备份；桌面网页和 Office 窗格刷新后才取得新云端代次，旧页面操作不得自动重试并带上新代次。

## 未接受政策的账户（2026-11-05）

两端后付费开关打开后，未接受 `2026-11-04` 政策的账户保持与开关关闭时完全相同的云端权限：有效订阅（含 3 GiB）照常读写、备份上传、项目写入与 Git 推送；非订阅用户与关闭时一样没有持久云空间。判定在两处一致：账户站 `cloudState` 对未接受账户按订阅规则给 `cloudAccess`（`reason` 为 `subscription` 或 `policy_required`），云端 `CloudStorageQuotaService.postpaidFor` 只对 `billing.accepted=true` 的账户启用后付费准入、PERSONAL 归属、代次与下载计费，其余账户走订阅配额。未接受账户授信为 0，账户站拒绝其存储与下载计量，不会产生后付费欠款。接受政策只增加后付费能力，不会让权限变差。账户站不可用时仍按原规则失败关闭；无账户映射的用户按“未接受”处理，与关闭开关时一样。

## 影子计量与上线前对账

云端 `AWD_CLOUD_POSTPAID_SHADOW`（默认关）：每 10 分钟为每个已映射账户测一次完整计费口径占用并上报 `shadow-storage`；计量下载路径（文件下载、备份/目录下载、Git 协议与对象分片）在交付后落一条 `shadow-pending` 收据，由同一定时任务上报 `shadow-egress`；每小时上报有数据但无账户映射的云端用户数（只含云端用户 ID）。影子模式不预占、不扣费、不改权限、不发通知、不触发清理，任何失败只记日志、不影响请求。账户站 `AWD_POSTPAID_SHADOW_ENABLED`（默认关）把上报写入独立影子账本 `postpaid_shadow_*`（迁移 48），计费路径不读它。

优先级：云端 `AWD_CLOUD_POSTPAID_ENABLED` 打开时影子模式整体失效（实时计费优先）；账户站对已接受政策账户的影子上报直接跳过（`skipped:'live'`）。因此任何账户任一时刻至多被一种模式计量，影子账本永远不会产生应付款。

运行影子期、对账脚本 `scripts/postpaid-shadow-reconcile.mts`（账户站仓库，只读打开 SQLite）、建议的通过标准与上线开关顺序见账户站仓库 `doc/postpaid-billing.md` 的 “Shadow period” 一节。简要顺序：两端部署 → 账户站开 `AWD_POSTPAID_SHADOW_ENABLED` 并重启 → 云端开 `AWD_CLOUD_POSTPAID_SHADOW` 并重启 → 至少 7 天并对账通过 → 云端开 `AWD_CLOUD_POSTPAID_ENABLED`、去掉影子开关并重启（此时无人接受，全部按订阅规则）→ 账户站开 `AWD_POSTPAID_ENABLED` 并重启 → 账户站关影子开关并重启。清理与人工核对开关不在此序列内，保持关闭。

## 失败和对账

下载 `pending` 回执表示发送字节已在本地持久记录，后台只重试结算，不重传文件。`reserved` 且执行结果不明时，保留预占并人工核对，不能推定整文件已送达，也不能仅因超时释放后静默重传。文件内容、用户凭据和支付密钥不进入诊断日志。

清理以账户、欠费事件、代次、资源清单摘要及逐项摘要绑定。已完成的远端回执重放只允许核对旧对象已经不存在并清理旧元数据；发现任何真实字节、身份变化或结果矛盾时转复核，不重新发物理删除。付款与删除许可由账户站事务裁决；已领取的批次可能继续，未领取的后续批次被阻止。付款不能恢复已物理删除的文件。清理冻结期间暂停云内容读取；核对完成且用户明确恢复后才开放剩余内容，不能将冻结状态显示为可下载。

支付查询结果未知、提醒无法证明持久送达、共享项目或历史归属不明，都阻止自动清理。人工核对必须保留证据，确认执行端已停止且原许可结果明确后处理；不能直接改数据库状态来“恢复正常”。账户站人工核对能力另设默认关闭开关 `AWD_POSTPAID_RECONCILIATION_ENABLED`。

首次提醒确认在原清理期限或之后才收到时，保持待复核，不能因回执刚补到而立即自动清理。应核对实际通知与回执证据，不把回执迟到直接认定为未通知；原第五天的存储止费时间不变。现有已签发对象许可核对接口不能用于自动解除这类通知审核。

发生账务异常先暂停新增后付费和清理；仍保留真实回执、支付和债务记录以便对账。禁用开关不是撤销账单，不得回滚覆盖已发生的还款或删除结果。

## 上架和渠道

保持各移动平台既有支付渠道。没有核验可用支付渠道的商店版本不新增外部充值链接；已完成政策接受的账户仍按服务端能力使用。未核验的商店收费入口须在该渠道正式启用前单独完成审核和验证，不能用普通网页跳转规避商店规则。
